# 폐쇄망 MCP 반입 패키지 목록

## 필수/옵션 패키지

| 패키지 | 용도 | 필수 여부 |
|---|---|---|
| mcp | MCP SDK 본체 — 게이트웨이 서버·클라이언트·중계 전부 이걸로 돌아감 | 필수 |
| pyyaml | config.yaml / servers.yaml 읽기·쓰기 | 필수 |
| requests | REST 커넥터 + 클라이언트의 vLLM 호출 | 필수 |
| oracledb | Oracle DB 쿼리 (db.py) | Oracle 쓸 때만 |
| pymssql | MSSQL 쿼리 (db.py) | MSSQL 쓸 때만 |

※ mcp 설치 시 딸려오는 의존성(starlette, uvicorn, httpx, pydantic 등)은
`pip download`가 자동으로 같이 받는다. 콘솔 서빙용 starlette도 포함이라 따로 안 받아도 된다.

## 반입 절차

1. 외부망 PC (서버 PC와 같은 OS·Python 버전):

```
pip download -r mcp-gateway/pkgs/requirements.txt -d mcp-gateway/pkgs/
```

2. pkgs 폴더째 USB/반입절차로 서버 PC 복사

3. 서버 PC (폐쇄망):

```
pip install --no-index --find-links mcp-gateway/pkgs -r mcp-gateway/pkgs/requirements.txt
```

## 주의

- wheel은 OS·Python 버전에 종속된다. 반입 전에 폐쇄망 쪽 `python --version` 확인 필수
- Oracle/MSSQL 안 쓰면 oracledb, pymssql은 requirements.txt에서 빼도 된다 (없어도 게이트웨이는 뜬다)
