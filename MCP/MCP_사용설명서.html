폐쇄망 AMHS MCP 시스템 — 사용설명서

서버 PC(게이트웨이) · 클라이언트 PC(LLM 앱) · 관리 콘솔 배치/실행 가이드 · 2026-07-08

1. 전체 구조

┌────────────────┐ ┌──────────────────┐ ┌─────────────┐ │ 니 PC │ HTTP │ 서버 PC │ │ DB PC 등 │ │ MCP 클라이언트 │ ─────► │ MCP 게이트웨이 │ ─────► │ Oracle │ │ + LLM 호출 │ 8010 │ (server.py) │ │ MSSQL │ │ (app.py) │ │ │ │ REST/파일 │ └────────────────┘ └──────────────────┘ └─────────────┘ ▲ ▲ vLLM(내부 LLM) 브라우저 → :8010/ (오프닝→콘솔)
  • 니 PC에서는 DB에 직접 붙지 않는다. 모든 접근은 게이트웨이(:8010)를 통해서만 이뤄진다.
  • 게이트웨이가 tool 13개를 제공하고, LLM이 질문에 따라 알아서 골라 호출한다.
  • 관리 콘솔(HTML)에서 서버 등록하면 게이트웨이가 servers.yaml에 저장한다.

2. 폴더 배치 — 어디에 뭘 넣나

PC넣을 폴더내용
서버 PCMCP\mcp-gateway\server.py · config.yaml · connectors\ · pkgs\
서버 PCMCP\INDEX\AMHS_MCP_OP.html (오프닝) · MCP_Console.html (콘솔)

⚠ INDEX 폴더는 반드시 mcp-gateway와 같은 상위 폴더에 둬야 한다 (게이트웨이가 ../INDEX/에서 콘솔을 찾는다). 위치 바꾸려면 config.yaml의 console_html, opening_html 수정.

3. 패키지 설치 (최초 1회)

폐쇄망이라 pip가 인터넷을 못 쓰므로, 외부망에서 미리 받아온 파일로 설치한다.

  1. 외부망 PC에서 (폐쇄망 PC와 같은 OS·Python 버전이어야 한다): 
    pip download -r mcp-gateway/pkgs/requirements.txt -d mcp-gateway/pkgs/
  2. pkgs\ 폴더째 USB/반입절차로 복사
  3. 폐쇄망 PC(서버·클라이언트 각각)에서: 
    pip install --no-index --find-links pkgs -r pkgs/requirements.txt
패키지용도필수 여부
mcpMCP SDK 본체 — 게이트웨이·클라이언트·중계 전부필수
pyyamlconfig.yaml / servers.yaml 읽기·쓰기필수
requestsREST 커넥터 + vLLM 호출필수
oracledbOracle DB 쿼리Oracle 쓸 때만
pymssqlMSSQL 쿼리MSSQL 쓸 때만

4. 서버 PC — 설정하고 실행

4-1. config.yaml 수정 (mcp-gateway 폴더)

항목수정할 내용
rest.endpoints내부 REST API 이름·주소 (MES, AMHS 등)
db.connectionsOracle DSN / MSSQL 호스트, 계정 — CHANGE_ME 교체
files.roots공유폴더 실제 경로 (예: C:/공유폴더)
relay.servers중계할 내부 MCP 서버 주소 (있을 때만)

4-2. 실행

# 명령 프롬프트에서
cd MCP\mcp-gateway
python server.py
  • 정상이면 Uvicorn running on http://0.0.0.0:8010 출력
  • 방화벽 8010 인바운드 허용 필요 (Windows 방화벽 → 고급설정 → 인바운드 규칙 → 포트 8010 TCP 허용)
  • server.py가 꺼지면 전부 멈춘다 — 중계·콘솔·저장 모두 이 프로세스가 담당

4-3. 자동 시작 (선택)

# 시작하기.bat 만들어서 시작 프로그램에 등록
@echo off
cd /d D:\MCP\mcp-gateway
python server.py

5. 관리 콘솔 — 브라우저에서 서버 등록

  1. 아무 PC 브라우저에서 http://서버PC_IP:8010/ 접속
  2. 오프닝 화면 10초 (우측 하단 SKIP ▸ 버튼으로 바로 넘어가기 가능)
  3. 콘솔 진입 → 헤더에 YAML 저장 연결됨 초록 칩 확인
  4. + 서버 등록 클릭 → 입력 항목:
    • 서버 이름 / 서버 주소(IP:포트) / 접속 아이디 / 비밀번호(가려짐)
    • 실행 명령 / 버전 / 태그 / 전송 방식(stdio·sse·http) / 상태
  5. 등록하면 서버 PC의 mcp-gateway\servers.yaml에 자동 저장
  6. 행 클릭 → 상세 드로어에서 수정 / 삭제
⚠ 비밀번호는 servers.yaml에 평문 저장된다. 서버 PC 접근 권한 관리 필수. 보안심사 대상이면 암호화 적용 검토.

6. 니 PC — 클라이언트 설정하고 실행

6-1. 설정 (mcp-client 폴더)

파일수정할 내용
config.yaml → llmvLLM 주소(http://GPU서버IP:8000/v1)와 모델명
config.yaml → gatewayhttp://서버PC_IP:8010/mcp
api_key.txtLLM API 키 한 줄 (환경변수 LLM_API_KEY로 대체 가능)

6-2. 실행

# 단발 질문
cd MCP\mcp-client
python app.py "M14 공유폴더 파일 목록 보여줘"

# 대화 모드 (계속 질문)
python app.py
질문> 어제 OHT 반송 로그 조회해줘
질문> 종료

실행하면 게이트웨이 연결됨 · tool 13개가 뜨고, LLM이 질문에 맞는 tool을 알아서 호출한다. tool 호출 과정은 [tool] fs_list {'root': 'share'} 식으로 표시된다.

7. 제공 tool 목록 (게이트웨이 내장, 13개)

분류tool하는 일
상태gateway_info게이트웨이 설정·상태 요약 (연결 확인용)
RESTrest_endpoints호출 가능한 내부 REST 목록
rest_call등록된 REST API 호출 (미등록 주소 차단)
DBdb_connections사용 가능한 DB 연결 목록
db_queryOracle/MSSQL 쿼리 — SELECT/WITH만 허용, 최대 500행
파일fs_roots접근 가능한 공유폴더 별칭 목록
fs_list폴더 내용 나열
fs_read텍스트 파일 읽기 (1MB 제한)
fs_write파일 쓰기 (감사 로그 기록)
fs_search파일명 패턴 검색 (*.csv 등)
중계relay_servers중계 가능한 내부 MCP 서버 목록
relay_list_tools내부 MCP 서버의 tool 목록 조회
relay_call내부 MCP 서버 tool 대신 호출

보안 가드: 등록 안 된 REST/DB/경로는 전부 차단, root 폴더 밖 접근 차단, SELECT 외 쿼리 차단. 모든 호출은 gateway.log에 남는다.

8. 문제 해결

증상원인·조치
콘솔에 "게이트웨이 미연결 · 임시 저장" 노란 칩server.py 안 떠 있음 → 서버 PC에서 python server.py 실행
클라이언트 연결 실패① 서버 PC 방화벽 8010 확인 ② config.yaml의 게이트웨이 IP 확인 ③ ping 서버IP
루트(/) 접속 시 404구버전 server.py — 최신 파일로 교체 후 재시작 (또는 /console로 직접 접속)
db_query 에러 "oracledb 미설치"pkgs에서 pip install --no-index oracledb
DELETE/UPDATE 쿼리 거부됨정상 동작 (기본 SELECT만). 허용하려면 config db.select_only: false — 비권장
등록 내용이 안 보임콘솔을 file://로 열었음 → http://서버IP:8010/으로 접속해야 YAML 연동
패키지 설치 실패외부망 PC와 폐쇄망 PC의 OS·Python 버전 불일치 → 같은 버전에서 다시 download

9. 요약 — 내일 할 일 순서

  1. 서버 PC MCP\mcp-gateway + MCP\INDEX 복사 → pkgs 오프라인 설치 → config.yaml 수정 → python server.py → 방화벽 8010
  2. 브라우저 http://서버IP:8010/ → 콘솔에서 서버 등록 → servers.yaml 저장 확인
  3. 니 PC MCP\mcp-client 복사 → config.yaml에 vLLM·게이트웨이 주소 → api_key.txt → python app.py "테스트 질문"
