V10.4 실시간 예측 시스템 - 코드 설명서

개요

10.4실시간평가.PY는 M14 TOTALCNT 1700+ 돌파를 10분 전에 예측하는 실시간 시스템이다.
V10.4 모델(XGBoost 회귀 + LightGBM 분류 + 투표)과 UI 급증/상태 분석을 결합했다.

실행 방법

python 10.4실시간평가.PY

필요 파일

파일경로설명
모델models/v10_4_m14_model.pklV10.4 학습 모델 (XGB+LGBM+스케일러)
데이터data/2025_DATA.CSV실시간 CSV (8.3.1과 동일)

출력 형식

prediction: 1,685
status: CRITICAL
status_Th: BOTTLENECK_EXPECTED
prediction_time: 2026-03-03 14:30
1700+ danger_probability: 75%
spike_info: D:M14AM14B +65, D:M14AM14BSUM +72
danger_count: 2, warning_count: 1

출력 필드 설명

필드설명
prediction10분 후 TOTALCNT 예측값 (앙상블 평균)
status기존 판정 - 10.4평가 투표+규칙 기반
LOW NORMAL CAUTION CRITICAL
status_Th심층 판정 - UI 급증+현재값+예측값 종합
NORMAL 양호예상 / OBSERVATION 관찰 / DANGER_EXPECTED 위험예상 / BOTTLENECK_EXPECTED 병목예상 / BOTTLENECK(1700_PREDICT-10min) 병목(1700예측-10분)
prediction_time예측 대상 시점 (현재 + 10분)
danger_probability1700+ 돌파 위험 확률 (0~100%)
spike_info급증 컬럼 정보 (D=danger, W=warning)
danger_countdanger 급증 컬럼 수
warning_countwarning 급증 컬럼 수

2. 함수 목록

함수역할

predict_latest()메인 함수 - 데이터 로드 → 예측 → 결과 반환

status (기존 판정) - 10.4평가 투표+규칙 방식

V10.4 모델의 투표 결과와 5가지 규칙으로 판정한다.

투표 구성

  • XGB 타겟 예측 >= 1700 → 1표
  • XGB 중요 예측 >= 1700 → 1표
  • XGB 보조 예측 >= 1700 → 1표
  • LGBM 타겟 분류 결과 (0 or 1)
  • LGBM 중요 분류 결과 (0 or 1)
  • LGBM 보조 분류 결과 (0 or 1)
  • (PDT 모델 있으면 +2표 추가)

최종 판정 규칙 (하나라도 충족 시 danger=1)

규칙조건
rule1투표 합계 >= 3
rule2LGBM 중요 확률 >= 0.50 AND 현재값 >= 1450
rule3XGB 중요 예측 >= 1680 AND 현재값 >= 1500
rule4현재값 >= 1600 AND 투표 합계 >= 2
rule5XGB 중요 예측 >= 1700

status 판정

status조건
CRITICALfinal_pred_danger == 1 (위 규칙 중 하나 이상 충족)
CAUTION앙상블 예측 >= 1600 또는 (현재값 >= 1500 AND 투표 2+)
NORMAL앙상블 예측 >= 900
LOW그 외

없는 컬럼 처리

모델의 FEATURE_GROUPS나 ANALYSIS_COLS에 있는 컬럼이 CSV에 없으면 자동으로 0으로 생성한다.
스케일러 차원을 유지하기 위해 컬럼을 제거하지 않고 0으로 채우는 방식이다 (10.4실시간.PY 동일).

if col not in df.columns:
    df[col] = 0
df[col] = pd.to_numeric(df[col], errors='coerce').fillna(0)
