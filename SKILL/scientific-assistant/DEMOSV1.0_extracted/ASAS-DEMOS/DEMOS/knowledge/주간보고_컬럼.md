# 주간보고 PPT 양식

## 제목 형식
`{프로젝트명}_주간보고_{YYYYMMDD}`
예시: smartATLAS_주간보고_20260408

## 슬라이드 레이아웃 (프로젝트당 1장)

### 구조
```
┌──────────────────────────────────────────────────┐
│ 1. {프로젝트명}                                    │
│ ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬ │ (빨강/노랑/파랑 구분선)
│ ┌───────────────────────┬───────────────────────┐ │
│ │      금주 실적          │      차주 계획         │ │ (헤더: 회색 배경)
│ ├────────┬──────┬───────┼────────┬──────┬───────┤ │
│ │추진 내용│ 납기  │진척율  │추진 내용│ 납기  │진척율  │ │ (서브헤더)
│ ├────────┼──────┼───────┼────────┼──────┼───────┤ │
│ │▶ 항목1  │04/22 │ 97%  │▶ 항목1  │04/22 │ 98%  │ │
│ │  1)상세 │      │      │  1)상세 │      │      │ │
│ │   ▶세부 │      │      │   ▶세부 │      │      │ │
│ │▶ 항목2  │04/08 │100%  │▶ 항목2  │04/08 │100%  │ │
│ │  1)상세 │      │      │        │      │      │ │
│ │   ▶세부 │      │      │        │      │      │ │
│ └────────┴──────┴───────┴────────┴──────┴───────┘ │
│ ┌──────────────────────────────────────────────┐   │
│ │ Issue 및 협의사항                               │   │ (하단 섹션)
│ └──────────────────────────────────────────────┘   │
│ ▶ : 진행중                                        │ (범례)
│                                    페이지 번호      │
└──────────────────────────────────────────────────┘
```

## 테이블 컬럼 정의

| 영역 | 컬럼 | 설명 |
|------|------|------|
| 금주 실적 | 추진 내용 | 이번 주 수행한 업무 (▶ 접두사) |
| 금주 실적 | 납기 | 마감일 (MM/DD 또는 MM월 DD일) |
| 금주 실적 | 진척율 | 완료율 (0~100%) |
| 차주 계획 | 추진 내용 | 다음 주 계획 업무 (▶ 접두사) |
| 차주 계획 | 납기 | 예정 마감일 |
| 차주 계획 | 진척율 | 예상 진척율 |

## 상태 기호
- `▶` : 진행중 (고정, 다른 기호 사용하지 않음)

## 데이터 입력 형식 (CSV)
```
금주 실적,,,,차주 계획,,
추진 내용,,납기,진척율,추진 내용,납기,진척율
▶ 업무제목,,날짜,진척율%,▶ 업무제목,날짜,진척율%
   1) 상세내용,,,,   1) 상세내용,,
     ▶세부사항,,,,     ▶세부사항,,
Issue 및 협의사항,,,,,,
```

## PPT 디자인 규격

### 슬라이드
- 크기: 와이드스크린 (13.33 x 7.5 인치)
- 배경: 흰색

### 제목
- 폰트: 맑은 고딕, 24pt, 볼드
- 색상: 검정 (#000000)
- 위치: 좌측 상단

### 구분선 바
- 3색 가로 바 (빨강 #FF0000 / 노랑 #FFD700 / 파랑 #4472C4)
- 제목 바로 아래

### 테이블 헤더
- 금주 실적 / 차주 계획: 회색 배경 (#D9D9D9), 볼드, 가운데 정렬
- 추진 내용 / 납기 / 진척율: 연회색 배경 (#F2F2F2), 볼드

### 테이블 본문
- 폰트: 맑은 고딕, 10pt
- 테두리: 얇은 검정선 (#000000)
- 추진 내용: 좌측 정렬
- 납기/진척율: 가운데 정렬

### Issue 및 협의사항
- 테이블 하단 별도 행
- 회색 배경 (#D9D9D9), 볼드

### 범례
- 슬라이드 하단: `● : 완료  ○ : 계획  ▶ : 진행중  ※ : Issue/특이사항`
- 폰트: 9pt

### 페이지 번호
- 하단 가운데

## python-pptx 생성 가이드
