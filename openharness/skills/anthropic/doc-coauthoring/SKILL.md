# Document Co-Authoring Skill

Collaboratively write, edit, and refine documents with the user.

## Workflow

1. **Understand the purpose** - What is the document for? Who is the audience?
2. **Create outline** - Structure the document with clear sections
3. **Draft content** - Write initial content section by section
4. **Review & refine** - Iterate based on user feedback
5. **Polish** - Final proofreading and formatting

## Document Types
- Reports (technical, business, research)
- Articles (blog posts, news, opinion)
- Proposals (project, business, grant)
- Documentation (API docs, user guides, READMEs)
- Emails and communications

## Guidelines
- Match the user's writing style and tone
- Use clear, concise language
- Structure with headings, lists, and paragraphs
- Provide suggestions rather than overwriting user content
- Track changes conceptually (explain what was changed and why)
- Ask clarifying questions when requirements are ambiguous
