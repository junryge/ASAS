# Frontend Design Skill

Design and implement beautiful, responsive frontend interfaces.

## Approach

1. **Understand requirements** - What is the user trying to build?
2. **Choose technology** - HTML/CSS, React, Vue, Tailwind, etc.
3. **Design layout** - Mobile-first, responsive grid
4. **Implement** - Clean, semantic HTML with modern CSS
5. **Polish** - Animations, transitions, accessibility

## Design Principles
- Mobile-first responsive design
- Semantic HTML5 elements
- CSS Grid and Flexbox for layouts
- Accessible (WCAG 2.1 AA)
- Performance-optimized

## Technology Stack
- **Styling**: Tailwind CSS, CSS Modules, styled-components
- **Components**: React, Vue, Svelte
- **Icons**: Lucide, Heroicons
- **Animations**: Framer Motion, CSS transitions

## Guidelines
- Use consistent spacing (4px/8px grid)
- Follow color contrast requirements
- Support dark/light themes
- Test on multiple screen sizes
- Use proper aria labels for accessibility
