| 지표 | 값 |
|------|-----|

| 5분 이내 완료 비율 | 91.7% |

| 구간 | 비율 |

## 4. 데이터 연관관계

### 4.1 데이터 간 연결 구조

```
  M14_OHT ←── VehicleId ──→ ts_resource
  (개별 VHL 상태)              (작업 명령/CommandId)
       │                           │
     집계(분)                    집계(분)
       ▼                           ▼
   스타 컬럼 ←── 시간 매칭 ──→ oht_time_avg
  (큐, 가동률)                  (TAT 평균)
       │
    큐↔속도
       ▼
   HID_INOUT ←── 주소 ──→ RAIL_CUT
  (구간 속도)              (차단 이벤트)
```

### 4.2 검증된 상관관계

| 관계 | 결과 | 의미 |
|------|------|------|
| 큐 → 반송시간 | 약한 양의 상관 (+0.15분) | 큐 올라가면 약간 느려지지만 미미 |
| 큐 → OBS 정지 | **거의 무관** | OBS는 큐가 아닌 물리적 혼잡이 원인 |
| 큐 → HID 속도 | **무관** | 속도는 물리적 구조에 의해 결정 |
| TAT → 시간대 | **무관** | 24시간 TAT 2.8분으로 균일 |
| 배차건수 → 반송시간 | **무관** | 시간당 ~20,000건 안정 |
| 주간 → 야간 | **차이 없음** | 24시간 동일 부하 |

## 5. 월드모델 구축 현황

### 5.1 각 데이터의 역할

```
  ┌──────────────────────────────────────────────────────────┐
  │                      월드 모델                             │
  │                                                          │
  │  ┌─────────────┐  개별 VHL 상태                           │
  │  │  M14_OHT    │  위치, 속도, 적재, 이동 방향              │
  │  │  oht_data   │  → "지금 각 차량이 어디서 뭘 하고 있나"    │
  │  └─────────────┘                                         │
  │         │                                                │
  │  ┌─────────────┐  작업 흐름                               │
  │  │ ts_resource │  배차→출발→도착→적재→하차                  │
  │  │  CommandId  │  → "어떤 작업이 진행 중인가"               │
  │  │  TAT=2.88분 │  → "작업 하나에 ~3분 소요"                │
  │  └─────────────┘                                         │
  │         │                                                │
  │  ┌─────────────┐  전체 부하                               │
  │  │ 스타 컬럼    │  큐, 가동률, 반송시간                     │
  │  │             │  → "시스템 전체가 얼마나 바쁜가"           │
  │  └─────────────┘                                         │
  │         │                                                │
  │  ┌─────────────┐  공간(구간) 상태                          │
  │  │ HID_INOUT   │  구간 속도, 통과량, 수용 한계              │
  │  │             │  → "어느 구간이 빠르고 느린가"             │
  │  └─────────────┘                                         │
  │         │                                                │
  │  ┌─────────────┐  이상 이벤트                              │
  │  │ RAIL_CUT    │  레일 차단, 영향 구간                     │
  │  │ (HIDOFF)    │  → "어느 길이 막혔나"                     │
  │  └─────────────┘                                         │
  └──────────────────────────────────────────────────────────┘
```

### 5.2 확보 현황

## 6. 예측 가능성 최종 판단

| 예측 대상 | 가능 여부 | 근거 |
|-----------|----------|------|
| 전체 물동량 | **가능** (5일치 확보 시) | 24시간 균일 ~20,000건/시 |
| TAT 범위 | **가능** | 2.88분 ± 1.8분 안정 |
| HID 저속 구간 | **가능** | 물리적 구조, 일별 변동 적음 |
| 시간대별 큐 | **조건부** (5일치 필요) | 2일만으로 패턴 미확정 |
| 개별 VHL 위치 (10분 후) | **불가** | TAT 2.88분 → 10분 내 3~4회 작업 전환 |
| 개별 VHL 경로 | **불가** | 경로 실시간 재계산 |
