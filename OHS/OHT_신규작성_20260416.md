## 1. 고객 피드백 반영

| # | 피드백 | 1차 (잘못) | 수정 |
|---|--------|-----------|------|
| 1 | R-Vehicle은 예비차량이 아님 | "R=예비차량" | **R=Reticle 반송 VHL** (반송물 종류만 다름) |
| 2 | 가동률 계산 방식 | 차량수 분포로 표현 | 가동OHT수 / 전체OHT수 |
| 3 | Priority ≠ 속도 | Priority를 속도로 해석 | **MCP 일괄 50 부여**, 속도와 무관 |
| 4 | 평균 TAT = 3.x분 | 7.8분으로 계산 | **실제 TAT = 2.88분** (ts_resource 기준) |
| 5 | Dijkstra 알고리즘 상이 | 코드 기반 설명 | 운영 알고리즘과 다를 수 있음 명시 |

```
  M14_OHT ←── VehicleId ──→ ts_resource
       │                         │
     집계(분)                  집계(분)
       ▼                         ▼
   스타 컬럼 ←── 시간 매칭 ──→ oht_time_avg
       │
    큐↔속도
       ▼
   HID_INOUT ←── 주소 ──→ RAIL_CUT
```

```
  ┌──────────────────────────────────────────────┐
  │                 월드 모델                       │
  │                                                │
  │  M14_OHT/oht_data → 개별 VHL 상태              │
```
