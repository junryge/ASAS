3. OHT Message Format (VHL_STATE_REPORT)
[0] 2[1] OHT[2] V00795[3] 1[4] 1[5] 0000[6] 1[7] 12340[8] 14[9] 12341[10] 4[11] 4[12] 4PDMV608[13] 36073[14] 00000000[15] 0000[16] 4ABL3301A_OUT04[17] 4ANZ19-701[18] 90[19] 0[20] 0
ColorFieldsDescription
ID[0] MessageId, [1] McpName, [2] VehicleId메시지/차량 식별
State[3] State1=RUN, 2=STOP, 3=ABNORMAL, 6=OBS_BZ_STOP, 7=JAM
Position[7] CurrentAddress, [8] Distance(100mm), [9] NextAddress현재 위치 (좌표 변환의 핵심)
Cargo[4] IsFull, [12] CarrierId, [13] Destination적재 정보 + 목적지
Port[16] SourcePort, [17] DestPort출발/도착 Port
Other[5][6][10][11][14][15][18][19][20]ErrorCode, RunCycle, VhlCycle, Priority 등
4. API Endpoints
MethodEndpointRequestResponseDescription
POST /api/oht-raw {"messages": ["2,OHT,..."]} {"status":"ok","updated":["V00795"]} raw OHT 메시지 수신 → 파싱 → 차량 위치 업데이트
POST /api/real-vehicles {"vehicles": [{...}]} {"status":"ok","count":5} 파싱된 차량 dict 리스트 직접 수신
GET /api/layout - {"nodes":[...],"edges":[...],"hidZones":[...]} 레이아웃 전체 데이터
GET /api/fab/list - {"fabs":["M14A","M14B",...]} 사용 가능 FAB 목록
POST /api/fab/switch {"fab":"M14B","prefix":"A"} {"status":"ok"} FAB 런타임 전환
WS /ws - {"type":"update","data":{...}} 0.5초 간격 차량 상태 브로드캐스트
