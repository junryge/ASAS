## 고객설명 자료에 들어간 수치 (2026년 7월 실측)

학습 4~6월(91일) → 평가 7월(31일, 학습 미사용). 심각 정체 4건.

| 설정 | 놓친 정체 | 평균 사전감지 | 10분+ 먼저 | 헛울림 |
|---|---|---|---|---|
| 민감 (p_on 0.30) | 0건 | 9.8분 | 3건 / 4건 | 2~3일에 1번 |
| 균형 (p_on 0.50) | 0건 | 3.8분 | 0건 | 8일에 1번 |
| 보수 (p_on 0.60) | 0건 | 3.8분 | 0건 | 한 달에 1번 |

**결과가 바뀌면 고쳐야 할 곳** (`고객설명_조기경보.html`):
1. "한눈에" 섹션 — 수치 타일 4개
2. 민감도 표 — 3행
3. 타임라인 도해 — 경보/정체 시각 텍스트
4. 맨 아래 footer — 학습·평가 기간

## 설명 요령 (고객 응대)

- 정확도(precision) 수치를 그대로 말하지 말고 **"확인 경보가 2~3일에 한 번"** 으로 환산해 말한다.
- 헛울림은 결함이 아니라 **고객이 고르는 설정**으로 제시한다 (민감도 표가 그 역할).
- 알람 부담이 크면 **2단 구성**을 권한다 — 1차는 화면 색만(민감), 2차는 알람(엄격).
- 한계는 먼저 밝힌다: 급발성 정체(17%)는 예측 대상이 아니고, 7월 사건이 4건으로 표본이 작다.
