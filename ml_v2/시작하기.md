# 시작하기 — 순서대로 이것만 하면 됩니다

## 0. 폴더 준비
```
작업폴더/
├── data.py  detect.py  evaluate.py  main.py     ← 압축 푼 파일
├── chronos_2/          ← Chronos-2 모델 폴더 (있으면 자동 사용)
├── RAW/                ← 4~5월 CSV (기존에 갖고 있던 것)
└── /data/raw7/         ← 7월 CSV (지금 다운로드 중인 것)
```

## 1. 다운로드 잘 됐나 확인
```bash
ls /data/raw7/*.CSV | wc -l
head -1 /data/raw7/M16A_HUBROOM_PR_20260701.CSV | tr ',' '\n' | wc -l
```
- 파일 31개, 컬럼 265개면 정상
- **컬럼이 59개면** → 4~5월과 안 맞으니 7월만 따로 학습해야 함 (아래 2-B)

## 2. 학습  (임계·기준을 뽑아 model_config.json 저장)

### 2-A. 컬럼 265개로 나왔으면 (4~7월 같이 학습) ← 권장
```bash
python main.py learn --train "RAW/*.CSV" "/data/raw7/*.CSV" --out-config model_config.json
```

### 2-B. 컬럼이 안 맞으면 (7월만)
```bash
python main.py learn --train "/data/raw7/*.CSV" --out-config model_config.json
```

출력에서 확인할 것:
```
임계   : 15.152   (10분 이동평균 p99.0)
심각사건: 36건 (월 8.9건) · 평균 52분 · 최장 156분
```

## 3. 감지 + 채점
```bash
python main.py all --config model_config.json --eval "/data/raw7/*.CSV" \
    --model chronos_2 --device cuda \
    --out-actions actions.csv --out-report report.csv
```

결과에서 볼 것:
```
backend=chronos_2       ← 이게 나와야 실모델 (baseline 이면 모델 못 찾은 것)
Recall    : xx%         ← 심각 정체를 얼마나 잡나
Precision : xx%         ← 경보가 얼마나 맞나
평균 lead : xx분
★ lead 분포 → ≥10분 전 xx건
```
- `report.csv` = 사건별 표 (엑셀로 열어보기)
- `actions.csv` = 분당 감지 결과

## 4. 헛울림 많으면 조이기
```bash
python main.py all --config model_config.json --eval "/data/raw7/*.CSV" \
    --model chronos_2 --device cuda --p-on 0.8 \
    --out-actions a2.csv --out-report r2.csv
```
`--p-on` 을 0.6 → 0.8 로 올리면 헛울림 줄고, 대신 놓치는 게 늘 수 있음.

## 문제 생기면
| 증상 | 원인 |
|---|---|
| `backend=baseline` | chronos_2 폴더 못 찾음 → `--model /경로/chronos_2` |
| `CSV 없음` | 글롭 경로 확인, 따옴표 꼭 붙이기 `"..."` |
| 느림 | `--stride 5` 추가 (5분 간격으로 평가) |
