# 실행 명령어 — 복사해서 붙여넣기

Windows cmd / Linux 공통. **한 줄 명령어**라 그대로 복붙하면 된다.
경로(`RAW`, `predict`)만 본인 환경에 맞게 바꾼다.

---

## 0. 설치 (처음 한 번)

```
pip install "chronos-forecasting>=2.0" torch
```

모델 폴더가 없으면 (폐쇄망이면 인터넷 PC 에서 받아 복사):
```
pip install "huggingface_hub[cli]"
huggingface-cli download amazon/chronos-2 --local-dir ./chronos_2
```

---

## ① 학습 — 기준 뽑기 (한 번만 · 모델 불필요 · 1분)

```
python main.py learn --train "RAW/M16A_HUBROOM_PR_202604*.CSV" "RAW/M16A_HUBROOM_PR_202605*.CSV" "RAW/M16A_HUBROOM_PR_202606*.CSV" --out-config model_config.json
```

→ `model_config.json` 생성. **이 파일이 ②③④의 입력이다.**

확인할 줄:
```
임계   : 14.765   (10분 이동평균 p99.0)
심각사건: 23건 (월 7.6건) · 평균 51.8분 · 최장 235분
```

---

## ② 평가 (스윕) — p_on 최적값 찾기 · 모델 1회 실행

```
python main.py sweep --config model_config.json --eval "RAW/M16A_HUBROOM_PR_202607*.CSV" --model chronos_2 --device cuda --horizon 30 --stride 3
```

→ p_on 별 비교표 + `actions_best.csv` `report_best.csv`

CPU 라 느리면 뒤에 `--stride 5` 추가, GPU 메모리 여유 있으면 `--batch 512` 추가.

---

## ③ 평가 (확정) — ②에서 고른 p_on 으로

```
python main.py all --config model_config.json --eval "RAW/M16A_HUBROOM_PR_202607*.CSV" --model chronos_2 --device cuda --horizon 30 --p-on 0.30 --out-actions actions.csv --out-report report.csv
```

→ `actions.csv`(분당 판정) · `report.csv`(사건별 표, 엑셀로 열기)

## ⑤ 상위 1% 임계 분석 — 시점 / 에피소드 / 컬럼

컬럼마다 상위 1% 임계(p99)를 구하고, 초과한 **시점**·**에피소드**·**컬럼요약**을 뽑는다.

```
python top1.py --data "RAW/*.CSV" --out-dir top1
```

정체 예측과 같은 기준(10분 이동평균)으로 보려면:
```
python top1.py --data "RAW/*.CSV" --window 10 --min-duration 10 --gap 10 --out-dir top1_ma
```

**학습기간 정체 사건(23건)과 교차분석** — 어떤 컬럼이 정체 때 같이 올랐고 몇 분 먼저 올랐나:
```
python top1.py --data "RAW/M16A_HUBROOM_PR_202604*.CSV" "RAW/M16A_HUBROOM_PR_202605*.CSV" "RAW/M16A_HUBROOM_PR_202606*.CSV" --window 10 --min-duration 10 --gap 10 --events --events-config model_config.json --lead 30 --no-points --out-dir top1_events
```

산출 (`--out-dir` 아래):

| 파일 | 내용 |
|---|---|
| `top1_columns.csv` | **컬럼별 임계·초과통계** ← 고객이 먼저 볼 표 |
| `top1_episodes.csv` | 에피소드 (시작·종료·지속·피크) |
| `top1_points.csv` | 초과 시점 목록 (`--no-points` 로 생략) |
| `top1_events.csv` | 정체 사건별 요약 + 겹친 상위 컬럼 |
| `top1_event_columns.csv` | 사건 × 컬럼 상세 (겹침·선행분·lift) |
| `top1_event_ranking.csv` | **선행지표 후보 순위** ← 원인 분석용 |

읽는 법 — `lift` = 정체 중 초과비율 ÷ 평상시 초과비율. **1.0 이면 우연 수준**,
클수록 그 컬럼이 정체와 진짜로 같이 움직인다는 뜻. `선행(분)`이 양수면 정체보다 먼저 올랐다.

자주 쓰는 옵션: `--pct 0.995`(상위 0.5%) · `--columns "컬럼명"`(특정 컬럼만)
· `--from 2026-04-01 --to 2026-06-30`(기간 제한) · `--min-lift 3`(순위표 문턱)

## 정상 동작 확인

②③ 에서 이 두 줄이 보여야 **실모델**이다.
```
[모델 호출 형태] inputs 3-D (n_series,n_variates,history)
채점 — ... (backend=chronos_2)
```
④ 에서는 이 줄:
```
모델 로드 완료: chronos_2 (cuda)
```
`baseline` 이 뜨면 모델 폴더를 못 찾은 것 → `--model D:\경로\chronos_2` 로 지정.

---

## GPU 없으면

`--device cuda` 를 빼면 CPU 로 돈다. ②③ 는 `--stride 5` 를 같이 붙일 것.
④ 실시간은 1분에 1회 호출이라 CPU 로도 충분하다.

---

## 자주 쓰는 옵션

| 옵션 | 기본 | 효과 |
|---|---|---|
| `--p-on` | 0.6 | 낮추면 더 일찍 경보(lead↑), 헛울림↑ · **권고 0.30** |
| `--horizon` | 30 | 앞으로 몇 분을 내다볼지 |
| `--context` | 90 | 직전 몇 분을 볼지 (수집기 윈도우와 동일) |
| `--stride` | 1 | ②③ 전용. N분 간격 평가 = N배 빠름 |
| `--batch` | 256 | GPU 메모리 여유 512 / 부족 64 |
| `--pct` | 0.99 | ① 전용. 임계 분위수. 낮추면 사건 수↑ |
| `--interval` | 60 | ④ 전용. 판정 주기(초) |
| `--offset` | 8 | ④ 전용. 매분 몇 초 뒤에 읽을지 |
