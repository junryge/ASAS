Freedom 코딩 어시스턴트 사용 설명서

도메인 지식 + 코딩 스킬 + LLM 으로 신규 프로그램을 완성하는 사내 폐쇄망용 워크벤치.
demos_v1 (PPT 플랫폼, 포트 10009) 와는 완전히 독립된 별도 플랫폼입니다.

1. 개요

다음 7가지 기능이 한 곳에 모인 사내 코딩 워크벤치입니다.

#기능위치
1코딩 어시스턴트 페르소나prompts.py
2API 토큰 인증TOKEN.TXT
3GGUF 자동 로딩MODEL_GGUF/
4SSE 토큰 스트리밍/api/code/chat/stream
5도메인 지식 등록·BM25 검색knowledge/
6Capacity 스타일 스킬 작성skills/<id>/SKILL.md
7컨텍스트 + 하네스 통합 동작 중engine.py + harness_setup.py

핵심 철학:

  • 자동 추론 비용 없음 — knowledge-search · 스킬 자동 선택 · 멀티에이전트 합성을 모두 끔. 사용자가 명시적으로 토글한 것만 동작.
  • 빠른 응답 — LLM 토큰이 SSE 로 즉시 화면에 떨어짐.
  • 독립 — code_assist_v1/ 한 폴더 안에 TOKEN, API 설정, GGUF, 스킬, 지식 모두 자체 보관.

4. 스킬

4.1. 스킬이란?

스킬 = LLM 의 "작업 매뉴얼" 한 장. SKILL.md 파일에 frontmatter(메타) + 본문(절차) 형식. 스킬을 활성화하면 본문이 시스템 프롬프트에 합쳐져 LLM 이 그 절차대로 행동합니다.

4.2. 시드된 69개 스킬 카테고리

첫 기동 시 scientific-skills 에서 코딩 관련 스킬 69개가 자동 복사됩니다.

4.3. 스킬 활성화

  1. 좌사이드 [스킬] 탭
  2. 항목 클릭 → 활성화 (좌측 액센트). 입력박스 위에 🛠 칩 표시
  3. 다시 클릭 → 비활성
  4. 우클릭 → SKILL.md 본문 열람·편집·삭제

4.4. 새 스킬 만들기

좌사이드 [스킬] 하단 ＋ → 모달:

---
name: my-fastapi-skill
description: FastAPI 라우트와 미들웨어를 작성한다 (라우터 매칭 키워드)
license: MIT
metadata:
  tags: [python, fastapi, backend]
---

# 절차
1. ...
2. ...

저장하면 skills/my-fastapi-skill/SKILL.md 자동 생성, ToolRegistry 즉시 동기화 → 사이드바에 등장.

💡 스킬 작성 팁: description 에 라우터 매칭 키워드, 본문은 절차형, 4000자 이내, 반-환각 가드 한 줄 권장.

5. 도메인 지식

knowledge/ 폴더는 빈 상태로 시작합니다. 사용자가 직접 등록합니다 (user_id 없이 평면).

5.1. 등록 방법 3가지

방법절차
인-앱 작성[지식] 탭 → ＋ → 파일명 + 마크다운 작성
파일 업로드[지식] 탭 → 업로드 → .md/.txt/.pdf/.docx → 텍스트 자동 추출
직접 복사탐색기에서 knowledge/ 에 .md 직접 넣기

5.2. 검색·답변

  1. 입력박스의 📚 → 그린 칩 📚 도메인 지식 ON
  2. 질문 입력 → 전송
  3. BM25 검색 → 상위 8개 문서 시스템 프롬프트 주입 → LLM 이 출처 명시하며 답변
⚠ 자동 트리거 없음 — 📚 버튼이 켜져 있을 때만 검색이 동작합니다.

5.3. BM25 알고리즘 (knowledge_store.py)

  • 한국어 2글자+ / 영문·숫자 2글자+ 토큰화
  • BM25 (k1=1.5, b=0.75)
  • 파일명 부분일치 보너스 +5, 본문 부분일치 +0.5
  • 상위 점수의 30% 미만은 제외
  • mtime 기반 인덱스 자동 갱신

업로드

  • 입력박스 📎 → 다중 파일 → 자동 업로드 + 자동 첨부 (보라 칩)

  • 📎첨부 버튼으로도 토글

  • 파일 1개당 최대 4000자
  • 전체 첨부 합쳐서 최대 16000자
  • 확장자 → 코드블록 언어 자동 감지

9. 컨텍스트 시스템

LLM 한 호출당 시스템 메시지가 어떻게 만들어지는지:

[1] 기본 시스템 프롬프트 (CODING_SYSTEM_PROMPT, 664자)
   ↓
[2] 반-환각 가드 (ANTI_HALLUCINATION, 176자)
   ↓
[3] 활성 스킬 본문 (각 SKILL.md, 컨텍스트 예산의 40% 까지)
   ↓
[4] 사용자 추가 지시 (⚙️ 프롬프트의 user_extra)
   ↓ → 여기까지가 system 메시지 #1

[5] 도메인 지식 (📚 ON 시, 최대 12000자)  → system 메시지 #2
[6] 워크스페이스 첨부 (최대 16000자)         → system 메시지 #3

[7] 대화 히스토리 (최근 12턴 트림)
   ↓
LLM 호출

구현 (engine.py):

  • build_coding_system_prompt(skill_ids, user_extra, n_ctx) — 1+2+3+4
  • build_knowledge_block(query, results) — 5
  • build_workspace_block(files) — 6
  • trim_message_history(messages, max_turns=12) — 7

10. 하네스 동작 중

하네스 = LLM 호출 외부의 운영 레이어. Tool 레지스트리, 라우터, 세션, 권한, 피드백을 담당합니다.

10.1. 구성요소 (harness-mvp/harness/)

모듈역할
Tool, ToolRegistry스킬 = Tool 로 등록·조회·실행

10.2. 통합 (harness_setup.py)

기동 시 setup_harness(app) 가:

  1. init_harness(SKILLS_DIR) — 빈 레지스트리 생성
  2. sync_skills() — code_assist_v1/skills/ 의 모든 SKILL.md 를 ToolRegistry 에 Tool 로 등록
  3. register_harness_routes(app) — /api/harness/* 16개 엔드포인트 등록

스킬 CRUD 시 자동 sync — routes_skills.py 의 create/update/delete 후 _sync_harness() 호출 → 추가·갱신·제거 즉시 반영.
