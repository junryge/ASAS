화이트보드

AI 답변 속 그림 코드(mermaid)를 글 대신 그림으로 보여 주는 기능입니다. 흐름도 · 시퀀스 · ERD · 상태도를 그리고, 그림은 PNG · SVG 로 저장해 보고서나 PPT 에 붙일 수 있습니다.

  • 설치 서버에 한 번 — 그 데모스를 쓰는 모두에게 보입니다
  • pip 설치 없음
  • 인터넷 필요 없음 (폐쇄망 그대로)

기능인가요, 스킬인가요?

답: 기능(프로그램)입니다. 스킬이 아닙니다.

스킬은 AI 에게 주는 글 지시문(.md)이라 그림을 그릴 수 없습니다. 화이트보드는 데모스 서버(파이썬)가 그림을 그리고 화면이 받아 붙이는 프로그램입니다. 둘은 짝으로 움직입니다 — 스킬이 AI 에게 "mermaid 로 써라" 하고, 화이트보드가 그 글을 그림으로 바꿉니다.

그림이 안 나올 때

넣는 법 — 서버 관리자가 한 번

  1. 이 추가팩 압축을 폴더째 풉니다 (화이트보드_추가팩 폴더가 생깁니다).
  2. 데모스 폴더(app.py 가 있는 곳)에서 설치기를 돌립니다. 무엇을 할지 먼저 보여 주고 y 를 누르면 설치합니다. 
    cd D:\데모스폴더
python 화이트보드_추가팩\whiteboard_install.py
    폴더가 다른 곳이면 --dir D:\데모스폴더, 먼저 보기만 하려면 --check.
  3. 데모스를 한 번 다시 켜고, 브라우저에서 Ctrl+F5. 콘솔에 화이트보드 라우트 등록 완료 가 보이면 됩니다.
  • 기존 파일은 덮어쓰지 않고 몇 줄씩 끼워 넣습니다. 고치기 전 파일은 옆에 .wb_backup 으로 남습니다.
  • 두 번 돌려도 같습니다. 자리를 못 찾은 파일은 건드리지 않고 "손으로" 라고 알려 줍니다.
  • sessions/ · users.json · TOKEN.TXT · api_config.json 은 건드리지 않습니다.
  • 빼기: python 화이트보드_추가팩\whiteboard_install.py --remove 후 다시 켜기.

데모스 없이 그림만 뽑기

그림 엔진은 파이썬 파일 하나라 따로도 씁니다. 마크다운 보고서 속 mermaid 를 모두 SVG 로 뽑을 수 있습니다.

python demos_v1\wb_render.py 보고서.md     → 보고서-1.svg, 보고서-2.svg …
python demos_v1\wb_render.py 그림.mmd      → 그림.svg

알아 둘 것

  • 그리는 종류: 흐름도 · 시퀀스 · ERD · 상태도. pie · gantt · classDiagram 등은 글 그대로 둡니다.
  • 상자가 수십 개인 큰 그림은 선이 겹칠 수 있습니다 — "나눠서 그려줘" 가 낫습니다.
  • 상태도의 메모(note), 묶음 안의 방향 바꾸기(direction)는 아직 그리지 않습니다.
