## M14 가 보는 것

| 룰 | 읽는 컬럼 | 임계 | 배점 |
|---|---|---|---|
| R-A′ 반송지연 | `M14.QUE.LOAD.AVGLOADTIME1MIN` | ≥ 3.3 분이 10분 중 1회+ | +10 |
| R-A′ 지속 | `(위와 같은 컬럼)` | ≥ 3.3×0.67 가 5분 중 3회+ | +5 |
| R-B 반입급증(30분) | `M14.QUE.ALL.3F_TO_HUB_JOB` | 30분 전 대비 +80 이상 | +10 |
| R-B 반입급증(10분) | `(위와 같은 컬럼)` | 10분 전 대비 +24 이상  (30분 임계의 30%) | +5 |
| R-C′ CNV 쏠림 | `M14.QUE.CNV.M14ATONORTHCURRENTQCNT`<br>`M14.QUE.CNV.M14ATOSOUTHCURRENTQCNT` | 북·남 중 큰 쪽 ÷ 합 ≥ 0.70 | +8 |
| R-D OHT 포화 | `M14.QUE.OHT.OHTUTIL` | OHT 가동률 ≥ 95.0% | +7 |
| SLA 4분초과 | `M14.QUE.ALL.TRANSPORT4MINOVERRATIO`<br>`M14.QUE.ALL.TRANSPORT4MINOVERCNT` | 비율 ≥ 25.0%  또는  건수 10분 +20 | +5 |
| 소터 대기 | `M14.SORTER.ABN.SORTERWAITCOUNTOVER` | 대기 ≥ 100 | +3 |
| MAXCAPA 축소 | `M14.QUE.CNV.3F_CNV_MAXCAPA` | 정상값보다 줄어든 컬럼 1개마다 | +10 × n |

```
area_score = min(50, 켜진 룰 배점의 합)
M14 가 받을 수 있는 최대: 50점
```

> ★M14 의 반송지연은 `AVGLOADTIME1MIN`(적재시간) 을 본다. M16HUB·M14B 처럼 `AVGTOTALTIME1MIN` 이 아니다.
