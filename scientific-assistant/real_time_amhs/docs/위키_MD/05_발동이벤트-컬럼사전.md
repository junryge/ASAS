## 매분 1행 · 131개 컬럼

**이벤트가 없는 분도 기록한다.** 없는 분을 빼면 나중에 분모를 못 센다.

| 컬럼 | 뜻 | 설명 |
|---|---|---|
| `file` | 입력 파일 이름 | 어느 원본에서 나온 행인지 |
| `datetime` | 그 분의 시각 | TOTAL.CSV·LLM.CSV 와 조인하는 열쇠 |
| `date` | 날짜만 | 일 단위로 묶을 때 |
| `time` | 시각만 | 하루 안의 시간대를 볼 때 |
| `stage` | 단계 0~3 | 0 이벤트없음 · 1 조기경보 · 2 주의보 · 3 확정 |
| `stage_name` | 단계 이름 | stage 를 사람 말로 |
| `prev_stage` | 직전 분의 단계 | 올라갔는지 내려갔는지 보려고 |
| `transition` | 단계가 바뀐 표시 | 바뀐 분에만 채워진다 (0 이면 비움) |
| `unified_risk_score` | ★ALL 점수 0~500 | 8영역 합 + 흐름·SLA·소터·MAXCAPA 가산. 관제 ALL 화면이 이 값을 본다 |
| `unified_risk_level` | ALL 등급 | 예측기 자체 6단계 (관제 등급과 다르다) |
| `hot_area` | 가장 높은 영역 | area_score 가 제일 큰 영역 |
| `hot_score` | 그 영역의 점수 | hot_area 의 area_score |
| `affected_areas` | 걸린 영역 목록 | area_score 가 전파 기준 이상인 영역을 ';' 로 |
| `propagation_chain` | 전파 사슬 | 최근 되돌아보기 구간 안에서 영역이 걸린 순서. 어디서 시작해 어디로 번졌는지 |
| `flow_signals` | 흐름 신호 | 평소 대비 배수가 임계를 넘은 노드를 ';' 로 |
| `maxcapa_signals` | 운영자 조치 신호 | 정상값보다 줄어든 MAXCAPA 컬럼 |
| `{영역}_score` | {영역} 영역 점수 0~50 | 그 영역의 룰 배점 합. FAB 화면이 보는 값이고 영역분리 뒤 area_score 가 된다 |
| `{영역}_signals` | {영역} 켜진 룰 이름 | '+' 로 이어 붙인다 — 어느 룰이 켜져서 그 점수가 나왔는지 |
| `{영역}_ra` | {영역} 반송/적재 시간 (분) | R-A′ 가 보는 실측값 — 그 분의 값 |
| `{영역}_rb_diff30` | {영역} 30분 증가량 | 허브행 대기 수가 30분 전보다 얼마나 늘었나 |
| `{영역}_rd_fab` | {영역} FAB 저장율(%) | R-D 가 보는 값 |
| `{영역}_stb_util` | {영역} STB 3F 저장율(%) | R-D 가 보는 또 하나 |
| `{영역}_rev_count` | 역증가 호기 수 | 합은 줄었는데 늘어난 리프터 개수 |
| `{영역}_rev_lids` | 역증가 호기 이름 | 어느 리프터인지 |
| `sla_{영역}` | {영역} 4분 초과 비율 (%) | SLA 가 보는 실측값 |
| `sorter_{영역}` | {영역} 소터 대기 초과 수 | 소터 룰이 보는 실측값 |
| `reason` | 판정 근거 한 줄 | 어느 영역의 어느 룰이 어떤 값으로 켜졌는지. stage 0 이면 비어 있다 |
| `{영역}_pts_RA` | {영역} · R-A′ 반송지연 배점 | 이 룰 하나가 준 점수. 룰 조합을 분석하려고 따로 남긴다 |
| `{영역}_pts_RA_sus` | {영역} · R-A′ 지속 배점 | 이 룰 하나가 준 점수. 룰 조합을 분석하려고 따로 남긴다 |
| `{영역}_pts_RB` | {영역} · R-B 반입급증(30분) 배점 | 이 룰 하나가 준 점수. 룰 조합을 분석하려고 따로 남긴다 |
| `{영역}_pts_RB_fast` | {영역} · R-B 반입급증(10분) 배점 | 이 룰 하나가 준 점수. 룰 조합을 분석하려고 따로 남긴다 |
| `{영역}_pts_RC` | {영역} · R-C′ 역증가·쏠림 배점 | 이 룰 하나가 준 점수. 룰 조합을 분석하려고 따로 남긴다 |
| `{영역}_pts_RD` | {영역} · R-D 저장/가동 포화 배점 | 이 룰 하나가 준 점수. 룰 조합을 분석하려고 따로 남긴다 |
| `{영역}_pts_SLA` | {영역} · SLA 4분초과 배점 | 이 룰 하나가 준 점수. 룰 조합을 분석하려고 따로 남긴다 |
| `{영역}_pts_SORT` | {영역} · 소터 대기/실패 배점 | 이 룰 하나가 준 점수. 룰 조합을 분석하려고 따로 남긴다 |
| `{영역}_pts_MAXCAPA` | {영역} · MAXCAPA 축소 배점 | 이 룰 하나가 준 점수. 룰 조합을 분석하려고 따로 남긴다 |
| `layer1_total` | 영역 점수 합 | 8영역 area_score 를 그냥 더한 값 |
| `flow_score` | 흐름 가산 | 흐름 노드 등급별 가산의 합 |
| `sla_score_total` | SLA 가산 | SLA 켜진 영역 수 × 배점 |
| `sorter_score_total` | 소터 가산 | 소터 켜진 영역 수 × 배점 |
| `mc_score_total` | MAXCAPA 가산 | 영역별 바뀐 컬럼 수 × 배점의 합 |
| `{영역}_ra_count` | {영역} R-A′ 초과 횟수 | 최근 10분 중 임계를 넘은 분의 수 |
| `{영역}_rb_diff10` | {영역} 10분 증가량 | 같은 것을 10분 창으로 — 빠르게 차오르는지 |
| `{영역}_rc_trend` | 리프터 합 변화 | 20분 전 대비 합계 증감 (음수여야 R-C′) |
| `{영역}_cnv_skew` | {영역} CNV 쏠림 비율 | 북/남 중 큰 쪽 ÷ 합 |
| `{영역}_rd_oht` | {영역} OHT 가동률 (%) | M16HUB 밖의 영역에서 R-D 가 보는 값 |
| `{영역}_sla_cnt` | {영역} 4분 초과 건수 | 비율이 아니라 건수. 10분 만에 20건 이상 늘면 SLA 가 켜진다 |
| `{영역}_sorter_fail` | {영역} 소터 반송 실패 | 1건만 있어도 소터 신호가 켜진다 |
| `{영역}_score_raw` | {영역} 영역 점수 (자르기 전) | 50 점에서 잘리기 전 원본. 캡에 걸렸는지 확인용 |

> `{영역}` 자리에 M16HUB · M14 · M14B · M16A · M16B · M16 · M16_PKT · M16_WT 가 들어간다.
