3) 점수 산정 방식 재설계

고객 지적: 이상 지표가 많으면 고점을 주는데, 특정 지표가 심각하면 고점을 못 준다. 한 지표가 많이 높으면 전체 점수도 많이 높아져야 한다.
→ 1)2) 가 정확히 그 증상이다. 아래가 그 답이다.

㉮ 초과 배율 가중 — 1)을 고친다

배율 r = 값 / 임계 r < 1.3 → 배점 × 1.0 (턱걸이 — 지금과 같다) 1.3 ≤ r < 2.0 → 배점 × 1.5 r ≥ 2.0 → 배점 × 2.5 (심각)

그림 3 — 이 규칙을 그날 두 분에 적용하면

심한 쪽이 27 → 52 로 오른다. 턱걸이 쪽은 55 → 55 로 그대로다 — 배율이 1배라 곱해도 안 오른다.
두 분의 차이가 28점 → 3점 으로 좁혀진다. 다만 ㉮만으로는 아직 뒤집히지 않는다 — 뒤집으려면 아래 ㉯(단독 심각 하한)가 같이 있어야 한다.

㉯ 단독 심각 하한 — "한 지표가 높으면 전체도 높게"

한 룰이라도 r ≥ 2.0 이면 그것만으로 위험 등급 하한을 보장한다. 지금은 아무리 심해도 다른 룰이 안 켜지면 경계에 머문다 — 16:55 가 그 예다(3.45배인데 경계).
