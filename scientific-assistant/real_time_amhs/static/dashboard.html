LLM 판단 일치 — 시스템별 설정

'LLM 판단 일치'의 재료입니다 — 시스템마다 매 주기, 아직 판단 안 한 분(分)을 LLM 에 물어 기록하고 30분 뒤 실제 데이터로 채점합니다. 느리면 그 시스템의 추론 주기를 늘리거나, 주기당 건수를 줄이거나, 판단을 '보는 화면만'으로 바꾸세요. 채점(검증) 자체는 LLM 을 안 써서 무료입니다.
