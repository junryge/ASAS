# 월드모델파생_실시간

월드모델파생(재생판)과 **같은 화면**인데, 재생 대신 로그프레소의 **지금** 데이터를 몇 초마다 받아 보여 줍니다.
확인용으로 따로 만든 판이에요. 월드모델파생 파일은 하나도 고치지 않았어요.

```
월드모델/
├─ 월드모델파생/          ← 그대로 (재생판, 10005)
└─ 월드모델파생_실시간/   ← 이 폴더 (실시간판, 10006)
```

## 실행

```
cd 월드모델파생_실시간
python main.py
```

브라우저에서 `http://localhost:10006`을 열고, 위의 **[▶ 실시간 PLAY]**를 누르면 돌기 시작해요.
`http://서버:10006/?fab=M16A&prefix=BR`처럼 지도를 골라서 바로 열 수도 있어요 (허브룸).

- **두 폴더가 나란히 있어야 해요.** 지도, 월드모델 엔진, 로그프레소 서버·키·쿼리를 옆 폴더 `월드모델파생`에서 가져다 써요 (복사 안 함).
  - 그래서 월드모델파생에서 고친 것(판정 기준, 서버 주소, 키)이 여기에도 그대로 들어와요.
  - 다른 자리에 두려면 환경변수 `WM_DIR`에 월드모델파생 폴더를 적어요.
- **추가로 깔 것이 없어요.** 표준 파이썬으로 떠요 (FastAPI·uvicorn 필요 없음). 로그프레소 쪽은 월드모델파생이 쓰던 것(requests·pandas)을 그대로 써요.
- 월드모델파생(10005)과 포트가 달라서 둘을 같이 띄워도 돼요.

## 키

월드모델파생과 같아요. 아래 중 하나만 있으면 돼요.

- `월드모델파생/logpresso_query.py`의 `API_KEY`
- 환경변수 `LP_API_KEY`
- 관제(real_time_amhs)의 `config.json` / `api_key.txt`

화면과 콘솔에는 키 끝 4자만 나와요.

## 지도 ↔ 테이블

관제 연동과 같은 짝이에요.

| 지도 | 테이블 | 관제 |
|---|---|---|
| M14A / A | oht_data_m14a | M14 |
| M14B / A | oht_data_m14b | M14B |
| M16A / A | oht_data_m16a | M16A |
| M16B / B | oht_data_m16b | M16B |
| M16A / BR | oht_data_m16br | M16HUB (허브룸) |

## 어떻게 도나

- **PLAY·정지:** [▶ 실시간 PLAY]를 눌러야 로그프레소를 묻고, [■ 정지]를 눌러야 멈춰요. 저절로 멈추지 않아요.
  - [⏸ 일시정지]는 화면만 그 자리에 세워요. 조회는 계속되고, 다시 PLAY 하면 지금으로 돌아와요.
  - 같은 서버를 여럿이 보면 PLAY·정지도 같이 써요. 한 사람이 정지해도 그 FAB을 PLAY 중인 다른 화면이 있으면 그대로 돌아요.
- **보는 FAB 하나만 물어요.** 화면에서 FAB을 옮기면 앞 FAB은 멈춰요 (그 FAB을 PLAY 중인 다른 화면이 없을 때).
- **조회는 작게 해요.** 한 번에 최대 60초씩 물어요. 5분치를 한 번에 물으면 응답이 중간에 끊겼어요 (`IncompleteRead`).
  - **처음:** 최근 60초만 받아서 바로 보여 줘요.
  - **그다음:** 5초마다 `[마지막으로 받은 시각 − 20초, 지금 − 3초]`를 '상세' 쿼리(MSG_ID=2)로 물어요. 많이 밀렸으면 60초씩 따라잡아요.
  - **거꾸로 채우기:** 조회할 때마다 60초씩 최근 5분까지 채워요. 멈춰 있어서 보고가 드문 차까지 지도에 올리려는 거예요. 상태줄에 "처음 5분 중 N분 채움"으로 나와요.
  - **응답이 끊기면:** 받은 데까지 쓰고, 다음엔 거기서부터 물어요. 시간순이라 앞부분은 온전해요.
  - **실패하면:** 묻는 폭을 반으로 줄여요 (최소 10초). 되면 다시 넓혀요.
  - **오래 쉬었다 다시 PLAY 하면:** 60초 넘게 못 물었을 때(정지·실패가 이어짐)는 밀린 것을 1분씩 따라잡지 않아요. 한 번에 '지금'으로 건너뛰고, 그 사이 구멍은 거꾸로 채워요. 따라잡으면 화면 시각이 여러 번 크게 뛰었어요.
  - **끝 3초는 빼요.** 지금 적재 중인 끝이라서요.
  - 20초를 겹쳐 묻는 건 늦게 들어온 줄을 받으려는 거예요. 같은 줄은 한 번만 얹어요.
- **보이는 방식:** 차가 5초마다 뛰지 않게, **8초 늦춰** 2초 칸을 차례로 보여 줘요.
  - **위 큰 시계(`OHT 05:13:03`)는 OHT 시각이에요.** 로그프레소 데이터 시각이고, PLAY 중에 초 단위로 흐르며 **절대 뒤로 가지 않아요**. 앞으로 크게 뛰는 건 정지했다 다시 PLAY 해서 지금으로 건너뛸 때뿐이에요.
  - **스코어 시각은 따로예요.** 상태줄 칩 `스코어 05:12 · M16HUB 30 · 정상`이 관제가 1분마다 매긴 시각이에요.
  - 늦춘 만큼은 위 상태줄에 "지금보다 N초 늦음"으로 나와요.
  - 바로바로 보고 싶으면 `LIVE_BUFFER_SEC=0`으로 두면 돼요. 대신 차가 5초마다 뛰어요.
- **판정:** 미보고(50초)·HT_STOP·JAM·전조 판정은 재생판과 같은 기준(`월드모델파생/config.py`)이에요.
  - 미보고는 데이터 시각 기준으로 재요. 로그프레소 적재가 통째로 늦으면 차가 아니라 수집 문제라서, 상태줄 배지가 빨갛게(데이터 늦음) 바뀌어요.

## 관제 스코어 (오른쪽 '스코어' 탭)

관제(real_time_amhs)가 매긴 **그 FAB의 스코어**를 그대로 받아 와요. 여기서 다시 계산하지 않아서 관제 표와 숫자가 같아요.

| 지도 | 관제 시스템 |
|---|---|
| M14A / A | M14 |
| M14B / A | M14B |
| M16A / A | M16A |
| M16B / B | M16B |
| M16A / BR | M16HUB |

- **위 상태줄:** `M16HUB 72 · 위험 · 위험중 2` 칩이 떠요. 누르면 스코어 탭이 열려요.
- **스코어 탭:**
  - 지금 점수·등급·알람·HI_FAB
  - 최근 60분 추이 (등급 띠 위에 선 하나, 마우스를 올리면 그 분)
  - 지금 걸린 것 (발동 룰·실제지표·HID_JAM·RET(레포트) 링크)
  - 최근 90분 목록 (전체·경계↑·위험↑·HID·RET 필터)
- **더블클릭:** 줄·추이를 더블클릭하면 관제와 같은 구간 그래프와 기여도가 떠요. 30분·1시간·2시간·6시간을 고를 수 있고, 그래프를 누르면 그 분이 아래에 고정돼요.
- **관제 주소:** 기본은 이 PC의 관제예요 (`real_time_amhs/config.json`의 `server.port`, 기본 8989). 다른 곳이면 환경변수 `GWANJE_URL=http://서버:8989`를 써요.
  - 관제가 꺼져 있으면 탭에 "관제에 닿지 않습니다"가 나와요. OHT 실시간은 그대로 돌아요.
  - 관제가 그 FAB을 '보는 중'으로 세는 것은 관제 화면을 연 것과 같아요.

## 화면에서 달라지는 것

- **숨김:** 속도, 프레임 막대, 구간 조회 칸(시작·끝·테이블·조회 로드)이 없어요. 구간 다시 보기는 월드모델파생(10005)에서 하면 돼요.
- **바뀜:** 재생 단추 셋은 자리·모양 그대로 [▶ 실시간 PLAY] [⏸ 일시정지] [■ 정지]가 됐어요.
- **추가:** 맨 위에 실시간 상태줄이 있어요.
  - `● 실시간`
  - 테이블
  - 화면 시각 (지금보다 몇 초 늦은지)
  - 차 수
  - 조회 (몇 초마다·한 번에 몇 초씩·처음 5분 중 몇 분 채움)
  - 응답 끊김 횟수
  - 실패 이유
  - 관제 스코어 칩
- **그대로:** 2D·유사 3D·아이소메트리, OHT 상태 목록, 미보고 필터, 정체 묶음, ⚙ 설정은 재생판과 같아요.

## 설정 (환경변수)

| 이름 | 기본 | 뜻 |
|---|---|---|
| `LIVE_PORT` | 10006 | 포트 |
| `LIVE_FAB` | (월드모델파생 기본) | 처음 지도, 예: `M16A/BR` |
| `LIVE_POLL_SEC` | 5 | 몇 초마다 조회 |
| `LIVE_STEP_SEC` | 60 | 한 번에 묻는 최대 폭 (끊기면 줄이세요) |
| `LIVE_EDGE_SEC` | 3 | '지금'의 끝 몇 초는 안 묻는다 |
| `LIVE_BUFFER_SEC` | 8 | 부드럽게 늦추는 초 (0이면 바로) |
| `LIVE_WARM_SEC` | 300 | 거꾸로 채우는 초 (처음 5분) |
| `LIVE_OVERLAP_SEC` | 20 | 겹쳐 묻는 초 |
| `LIVE_JUMP_SEC` | 60 | 이만큼 못 물었으면 따라잡지 않고 지금으로 |
| `LIVE_TIMEOUT_SEC` | 60 | 한 번 묻는 데 기다리는 초 |
| `GWANJE_URL` | 이 PC의 관제 (config 포트) | 관제 스코어를 받는 곳 |
| `WM_DIR` | `../월드모델파생` | 월드모델파생 폴더 |

## 잘 안 될 때

- **상태줄 "조회 실패 — HTTP 401":** 키와 서버가 안 맞아요. 상태줄 배지에 마우스를 올리면 서버 주소와 키 끝 4자가 나와요.
- **콘솔 "응답이 중간에 끊겼습니다":** 받은 데까지 쓰고 이어서 물어요. 자주 나오면 `LIVE_STEP_SEC=30`처럼 폭을 줄여요.
- **스코어 탭 "관제에 닿지 않습니다":** 관제(8989)가 켜져 있는지, 주소가 다르면 `GWANJE_URL`을 봐요.
- **"지금보다 N초 늦음"이 계속 커짐:** 로그프레소 적재가 늦는 거예요 (배지 빨강, "데이터 늦음").
- **조회 상태 한눈에 보기:** `http://서버:10006/api/live/status`

## 시험

```
cd 월드모델파생_실시간
python -m unittest discover -s tests -t .
```

`tests/mock_logpresso.py`가 진짜와 같은 주소로 답하는 가짜 로그프레소예요 (응답 끊기 흉내도 돼요).
`tests/mock_gwanje.py`는 스코어 중계를 시험하는 가짜 관제예요.
지도 레일 위로 지금 시각의 차 줄을 만들어 줘요 (운행 32 · JAM 4 · HT_STOP 1 · 미보고 3). 진짜 데이터는 하나도 없어요.

손으로 띄워 보는 방법은 아래와 같아요. 이 PC에 pandas가 없을 때만 `PYTHONPATH=tests/_stub`가 필요해요.

```
MOCK_LP_KEY=dummy-key python tests/mock_logpresso.py 18888
LP_HOST=127.0.0.1 LP_PORT=18888 LP_API_KEY=dummy-key LIVE_FAB=M16A/BR python main.py
```
