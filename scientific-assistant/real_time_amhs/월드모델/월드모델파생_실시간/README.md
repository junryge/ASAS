# 월드모델파생_실시간

월드모델파생(재생판)과 **같은 화면**인데, 재생 대신 로그프레소의 **지금** 데이터를 몇 초마다 받아 보여 줍니다.
확인용으로 따로 만든 판이에요. 월드모델파생 파일은 하나도 고치지 않았어요.

```
월드모델/
├─ 월드모델파생/          ← 그대로 (재생판, 10005)
└─ 월드모델파생_실시간/   ← 이 폴더 (실시간판, 10006)
```

## 실행

```
cd 월드모델파생_실시간
python main.py
```

브라우저에서 `http://localhost:10006`을 엽니다.
`http://서버:10006/?fab=M16A&prefix=BR`처럼 지도를 골라서 바로 열 수도 있어요 (허브룸).

- **두 폴더가 나란히 있어야 해요.** 지도, 월드모델 엔진, 로그프레소 서버·키·쿼리를 옆 폴더 `월드모델파생`에서 가져다 써요 (복사 안 함).
  - 그래서 월드모델파생에서 고친 것(판정 기준, 서버 주소, 키)이 여기에도 그대로 들어와요.
  - 다른 자리에 두려면 환경변수 `WM_DIR`에 월드모델파생 폴더를 적어요.
- **추가로 깔 것이 없어요.** 표준 파이썬으로 떠요 (FastAPI·uvicorn 필요 없음). 로그프레소 쪽은 월드모델파생이 쓰던 것(requests·pandas)을 그대로 써요.
- 월드모델파생(10005)과 포트가 달라서 둘을 같이 띄워도 돼요.

## 키

월드모델파생과 같아요. 아래 중 하나만 있으면 돼요.

- `월드모델파생/logpresso_query.py`의 `API_KEY`
- 환경변수 `LP_API_KEY`
- 관제(real_time_amhs)의 `config.json` / `api_key.txt`

화면과 콘솔에는 키 끝 4자만 나와요.

## 지도 ↔ 테이블

관제 연동과 같은 짝이에요.

| 지도 | 테이블 | 관제 |
|---|---|---|
| M14A / A | oht_data_m14a | M14 |
| M14B / A | oht_data_m14b | M14B |
| M16A / A | oht_data_m16a | M16A |
| M16B / B | oht_data_m16b | M16B |
| M16A / BR | oht_data_m16br | M16HUB (허브룸) |

## 어떻게 도나

- **조회:** 5초마다 `[마지막으로 받은 시각 − 20초, 지금]`을 '상세' 쿼리(MSG_ID=2)로 물어요.
  - 처음 열 때는 최근 5분치를 받아요. 멈춰 있어서 보고가 드문 차까지 지도에 올리려는 거예요.
  - 20초를 겹쳐 묻는 건 로그프레소에 늦게 들어온 줄을 받으려는 거예요. 같은 줄은 한 번만 얹어요.
- **보이는 방식:** 차가 5초마다 뛰지 않게, **8초 늦춰** 2초 칸을 차례로 보여 줘요.
  - 늦춘 만큼은 위 상태줄에 "지금보다 N초 늦음"으로 나와요.
  - 바로바로 보고 싶으면 `LIVE_BUFFER_SEC=0`으로 두면 돼요. 대신 차가 5초마다 뛰어요.
- **판정:** 미보고(50초)·HT_STOP·JAM·전조 판정은 재생판과 같은 기준(`월드모델파생/config.py`)이에요.
  - 미보고는 데이터 시각 기준으로 재요. 로그프레소 적재가 통째로 늦으면 차가 아니라 수집 문제라서, 상태줄 배지가 빨갛게(데이터 늦음) 바뀌어요.
- **같이 보기:** FAB(지도)마다 조회는 하나예요. 여럿이 같은 지도를 보면 같이 써요.
- **자동 멈춤:** 아무도 5분 동안 안 보면 조회를 멈추고, 다시 열면 이어서 받아요.
- **실패할 때:** 조회가 실패하면 상태줄에 빨간 글자로 이유가 나오고, 점점 천천히 다시 물어요 (최대 1분 간격).

## 화면에서 달라지는 것

- **숨김:** 재생·정지·속도, 프레임 막대, 구간 조회 칸(시작·끝·테이블·조회 로드)이 없어요. 구간 다시 보기는 월드모델파생(10005)에서 하면 돼요.
- **추가:** 맨 위에 실시간 상태줄이 있어요.
  - `● 실시간`
  - 테이블
  - 화면 시각 (지금보다 몇 초 늦은지)
  - 차 수
  - 몇 초마다 조회하는지
  - 실패 이유
- **그대로:** 2D·유사 3D·아이소메트리, OHT 상태 목록, 미보고 필터, 정체 묶음, ⚙ 설정은 재생판과 같아요.
- **아직 빈 것:** 스타 지표·예측 칸은 비어 있어요. 실시간판은 아직 OHT 상태(oht_data)만 받아요.

## 설정 (환경변수)

| 이름 | 기본 | 뜻 |
|---|---|---|
| `LIVE_PORT` | 10006 | 포트 |
| `LIVE_FAB` | (월드모델파생 기본) | 처음 지도, 예: `M16A/BR` |
| `LIVE_POLL_SEC` | 5 | 몇 초마다 조회 |
| `LIVE_BUFFER_SEC` | 8 | 부드럽게 늦추는 초 (0이면 바로) |
| `LIVE_WARM_SEC` | 300 | 처음 열 때 받는 초 |
| `LIVE_OVERLAP_SEC` | 20 | 겹쳐 묻는 초 |
| `LIVE_IDLE_STOP_SEC` | 300 | 아무도 안 보면 멈추는 초 |
| `WM_DIR` | `../월드모델파생` | 월드모델파생 폴더 |

## 잘 안 될 때

- **상태줄 "조회 실패 — HTTP 401":** 키와 서버가 안 맞아요. 상태줄 배지에 마우스를 올리면 서버 주소와 키 끝 4자가 나와요.
- **"지금보다 N초 늦음"이 계속 커짐:** 로그프레소 적재가 늦는 거예요 (배지 빨강, "데이터 늦음").
- **조회 상태 한눈에 보기:** `http://서버:10006/api/live/status`

## 시험

```
cd 월드모델파생_실시간
python -m unittest discover -s tests -t .
```

`tests/mock_logpresso.py`가 진짜와 같은 주소로 답하는 가짜 로그프레소예요.
지도 레일 위로 지금 시각의 차 줄을 만들어 줘요 (운행 32 · JAM 4 · HT_STOP 1 · 미보고 3). 진짜 데이터는 하나도 없어요.

손으로 띄워 보는 방법은 아래와 같아요. 이 PC에 pandas가 없을 때만 `PYTHONPATH=tests/_stub`가 필요해요.

```
MOCK_LP_KEY=dummy-key python tests/mock_logpresso.py 18888
LP_HOST=127.0.0.1 LP_PORT=18888 LP_API_KEY=dummy-key LIVE_FAB=M16A/BR python main.py
```
