# 월드모델파생 (10005) — 리플레이 · 실시간

한 서버, 한 주소예요: `http://서버:10005`. 맨 위 **[⏪ 리플레이 | ● 실시간]**으로 모드를 바꿔요.

- **리플레이:** 지난 구간을 로그프레소에서 조회해 다시 봐요. 예전 그대로예요.
- **실시간:** 로그프레소의 **지금** 데이터를 몇 초마다 받아 봐요. 지금 보는 FAB 하나만 물어요.

따로 띄우던 실시간판(`월드모델파생_실시간`, 10006)은 여기에 합쳤어요. 그 폴더는 이제 필요 없어요.

```
python main.py          → http://localhost:10005
```

## 모드 바꾸기

- 고른 모드는 이 브라우저에 남아요. 다시 열면 마지막 모드로 열려요.
- 주소로 바로 열 수 있어요.
  - `http://서버:10005/?mode=live` → 실시간
  - `http://서버:10005/?mode=live&fab=M16A&prefix=BR` → 허브룸 실시간
- 관제에서 넘어온 구간 조회(`?auto=1…`)는 늘 리플레이로 열려요.
- **탭마다 따로예요.** 한 탭은 지난 구간을 리플레이로, 다른 탭은 실시간으로 같이 볼 수 있어요.
  - 같은 브라우저의 탭들은 FAB 고르기는 같이 써요. 예전부터 한 사람으로 보던 것과 같아요.
- **실시간으로 가면** 리플레이는 그 자리에 멈춰 있어요. 돌아와서 [▶ 재생]을 누르면 이어서 돌아요.
- **리플레이로 돌아가면** 실시간 PLAY는 놓아요. 그 FAB을 보는 다른 사람이 없으면 로그프레소 조회가 멎어요.

## 실시간 모드

| 단추 | 하는 일 |
|---|---|
| ▶ 실시간 PLAY | 로그프레소를 묻기 시작해요 (보는 FAB 하나만). 시계가 흘러요. |
| ⏸ 일시정지 | 화면만 그 자리에 세워요. 조회는 계속되고, 다시 PLAY 하면 지금으로 와요. |
| ■ 정지 | 조회를 멈춰요. 저절로 멈추지 않아요. |

- **숨는 것:** 구간 조회 칸(시작·끝·테이블·조회 로드), 속도, 프레임, 슬라이더. 리플레이에만 있어요.
- **생기는 것:**
  - 위 상태줄: 테이블 · OHT 시각(지금보다 몇 초 늦은지) · 차 수 · 조회 상태 · 관제 스코어 칩
  - 오른쪽 '스코어' 탭
- **위 큰 시계 `OHT 05:13:03`은 OHT 시각이에요.** 로그프레소 데이터 시각이고, 절대 뒤로 가지 않아요.
  - 스코어 시각은 따로예요. 상태줄 칩 `스코어 05:12 · M16HUB 30 · 정상`이 관제가 1분마다 매긴 시각이에요.
- **조회는 작게 해요.** 한 번에 최대 60초씩 물어요. 5분치를 한 번에 물으면 응답이 중간에 끊겼어요 (`IncompleteRead`).
  - 처음에는 최근 60초만 받아 바로 보여 줘요.
  - 그다음엔 5초마다 묻고, 조회할 때마다 60초씩 거꾸로 채워 최근 5분까지 채워요.
  - 끊긴 응답은 받은 데까지 써요. 실패하면 묻는 폭을 반으로 줄여요.
  - 오래 쉬었다 다시 PLAY 하면 밀린 것을 따라잡지 않고 지금으로 한 번에 건너뛰어요.
- **판정**(미보고 50초 · HT_STOP · JAM · 전조)은 리플레이와 같은 기준(`config.py`)이에요. 지도·존도 리플레이와 한 벌을 같이 써요.

### 스코어 탭 (관제가 매긴 그 FAB의 점수)

| 지도 | 관제 시스템 |
|---|---|
| M14A / A | M14 |
| M14B / A | M14B |
| M16A / A | M16A |
| M16B / B | M16B |
| M16A / BR | M16HUB |

- 지금 점수 · 등급 · 알람 · HI_FAB, 최근 60분 추이, 지금 걸린 것(발동 룰 · 실제지표 · HID_JAM · RET 링크)을 보여 줘요.
- **개수:** 필터 단추마다 몇 줄인지 나와요. 단추를 누르면 그 수만큼 줄이 나와요.
  - 예: `전체 90 · 경계↑ 67 · 위험↑ 44 · HID·RET 1`
  - 위 요약에는 HID_JAM과 RET를 나눠서 세요: `최근 90분 · 경계↑ 67 · 위험↑ 44 · HID_JAM 1 · RET 1`
- 줄이나 추이를 더블클릭하면 관제와 같은 구간 그래프(스코어 + 그 줄 실제지표)가 떠요.
- 점수를 여기서 다시 계산하지 않아요. 그래서 관제 표와 숫자가 같아요.
- 관제 주소는 **넣지 않아도 스스로 찾아요** — 찾아 둔 주소 → 이 PC의 관제(`real_time_amhs/config.json`의 `server.port`, 기본 8989) → 관제 설정의 `server.host` IP → 관제 화면 'OHT 재생'에서 넘어온 주소 → 이 서버에 들어온 주소 차례로 물어 **답하는 관제**를 써요. 사내 프록시는 타지 않아요. 다른 서버의 관제를 찾으면 이 PC의 `관제_주소.json`에 적어 두어(저장소에는 안 올라가요) 다시 띄워도 처음부터 그 관제를 봐요. 스코어 탭 맨 위에 지금 묻는 관제 주소가 보여요. 환경변수 `GWANJE_URL`이 있으면 그것만 봐요.
  - 관제가 꺼져 있으면 탭에 "관제에 닿지 않습니다"가 나와요. OHT 실시간은 그대로 돌아요.

## 여러 사람이 볼 때

- **로그프레소 조회는 FAB마다 하나예요.** 몇 명이 같은 FAB을 보든 조회는 한 번이에요.
- **PLAY·정지는 사람마다예요.**
  - 한 사람이 정지해도 그 FAB을 PLAY 중인 사람이 남아 있으면 계속 돌아요.
  - 아무도 안 남으면 멈춰요.
- 이미 누가 PLAY 중인 FAB을 실시간으로 열면 같이 PLAY 상태로 봐요.
- 1초마다 보내는 장면(차 수백 대, 약 100KB)은 FAB마다 한 번만 만들어 나눠 써요. 사람마다 다른 것은 위 상태줄뿐이에요.
- **화면을 보고 있는 사람은 세션 수 한도(`OHT_SESSION_MAX`, 기본 24)로 밀려나지 않아요.**
  - 한도는 리플레이로 하루치를 불러 놓고 떠난 사람 몫의 메모리를 비우려는 거예요.
  - 창을 닫고 한 시간(`OHT_SESSION_TTL`)이 지나면 그 사람 세션을 치워요. 실시간 PLAY도 그때 놓아요.
- 관제 스코어도 5초 안의 같은 물음은 관제에 다시 묻지 않아요.

## 배경 4종 (2D · 유사 3D · 아이소메트리 같이)

위 **[배경 다크 | 화이트 | 네이비 | 고대비]**나 ⚙ 설정의 '배경'에서 골라요.

- 세 보기(2D · 유사 3D · 아이소메트리)가 같은 배경을 써요.
- 상단·패널도 같이 바뀌어요.
- 고른 값은 이 브라우저에 남아요.

| 배경 | 맵 바탕 | 레일 · 글자 |
|---|---|---|
| 다크 | 예전 어두운 화면 (⚙ '다크 전용'에서 바탕·레일 색을 바꿀 수 있음) | 밝은 레일 · 노란 글자 |
| 화이트 | 현장 HMI처럼 밝은 회색 (기본) | 검은 레일 · 검은 글자 |
| 네이비 | 관제 네이비와 같은 색 (`#0E1E30`) | 밝은 레일 · 노란 글자 |
| 고대비 | 검정 | 흰 레일 · 노란 글자 (멀리서 · 밝은 방에서 읽기 쉽게) |

- 바탕만 바꾸면 레일·글자가 바탕에 묻혀요 (브릿지 모니터에서 흰 바탕에 흰 글자가 안 보였던 일). 그래서 배경마다 레일·글자 색도 같이 바꿔요.
  - 시험이 레일 대비 3:1 이상, 글자 대비 4.5:1 이상인지 재요.
- 아이소메트리는 FAB 바닥은 밝은 회색 그대로이고, 그 바깥 배경이 바뀌어요.

## 설정 (환경변수)

| 이름 | 기본 | 뜻 |
|---|---|---|
| `LIVE_POLL_SEC` | 5 | 몇 초마다 조회 |
| `LIVE_STEP_SEC` | 60 | 한 번에 묻는 최대 폭 (응답이 끊기면 줄이세요) |
| `LIVE_EDGE_SEC` | 3 | '지금'의 끝 몇 초는 안 묻는다 (적재 중) |
| `LIVE_BUFFER_SEC` | 8 | 부드럽게 늦추는 초 (0이면 바로, 대신 차가 5초마다 뜀) |
| `LIVE_WARM_SEC` | 300 | 거꾸로 채우는 초 (처음 5분) |
| `LIVE_OVERLAP_SEC` | 20 | 늦게 들어온 줄을 받으려고 겹쳐 묻는 초 |
| `LIVE_JUMP_SEC` | 60 | 이만큼 못 물었으면 따라잡지 않고 지금으로 |
| `LIVE_TIMEOUT_SEC` | 60 | 한 번 묻는 데 기다리는 초 |
| `GWANJE_URL` | (없음 — 스스로 찾음) | 관제 스코어를 받는 곳을 못 박을 때만 — 있으면 그것만 본다 |
| `OHT_SESSION_MAX` | 24 | 세션 수 한도 (보고 있는 사람은 안 셈) |
| `OHT_SESSION_TTL` | 3600 | 이만큼 안 오면 세션을 치움 (실시간 PLAY도 놓음) |

로그프레소 서버·키는 리플레이와 같아요 (`logpresso_query.py`의 `SERVERS` · `API_KEY`, 또는 환경변수 `LP_API_KEY`). 화면과 콘솔에는 키 끝 4자만 나와요.

## 잘 안 될 때

- **상태줄 "조회 실패 — HTTP 401":** 키와 서버가 안 맞아요. 상태줄 배지에 마우스를 올리면 서버 주소와 키 끝 4자가 나와요.
- **"응답이 중간에 끊겼습니다"가 자주 나옴:** `LIVE_STEP_SEC=30`처럼 묻는 폭을 줄여요.
- **"지금보다 N초 늦음"이 계속 커짐:** 로그프레소 적재가 늦는 거예요 (배지 빨강, "데이터 늦음").
- **스코어 탭 "관제에 닿지 않습니다" · 경계가 안 보임:** 관제(8989)가 켜져 있는지 봐요. 관제가 다른 서버에만 있고 이 PC에서 처음 여는 것이면 관제 화면의 'OHT 재생'으로 한 번 들어오면 그 주소를 찾아 적어 둬요. 그래도 안 닿으면 관제 서버 방화벽에서 TCP 8989 인바운드를 열어요.
- **조회 상태를 한눈에 보기:** `http://서버:10005/api/live/status`

## 적용 방법

### 1. dashboard.html 교체
```
WORD_MODEL/WORLD_SIM/dashboard.html
```
위 경로에 포함된 `dashboard.html`로 덮어쓰기.

### 2. data_loader.py 수정
`data_loader.py`의 `DateDataLoader` 클래스 안에서:

**[A] 새 메서드 추가** (예: `get_hid_speed_summary` 뒤)
→ `data_loader_railcut_patch.py`의 `_get_active_rail_cuts` 메서드 복사해서 붙여넣기

**[B] `get_frame_at` 메서드 안의 RAIL_CUT 블록 교체**

기존:
```python
# RAIL_CUT: 현재까지 발생한 이벤트
rail_cuts = []
for t, ev in self.rail_cut_events:
    if t <= target_time:
        rail_cuts.append(ev)
```

교체:
```python
# RAIL_CUT: 페어 매칭으로 현재 활성 차단만 반환
rail_cuts = self._get_active_rail_cuts(target_time)
```

### 3. CSV 파일
기존 포맷 그대로 사용. 변경 없음.

```
OHS_DATA_MD/
  20260414/LOGPRESSO_OHT_RAIL_CUT_20260414.CSV
  20260415/LOGPRESSO_OHT_RAIL_CUT_20260415.CSV
  ...
```

### 4. 서버 재시작
```bash
cd WORD_MODEL/WORLD_SIM
python main.py
```

## 동작 로직

- **STATE=ABNORMAL** → 맵에 ⛔ 표시 (빨간 점선 + X 마커, 깜빡임)
- **STATE=NORMAL**   → 맵에서 자동 제거
- **NORMAL 없으면**   → 계속 표시 유지
- **ABNORMAL 없이 NORMAL만 오면** → 조용히 무시 (에러 없음)

데이터가 말하는 대로 그대로 믿고 처리.

## 남은 결정 사항

**날짜 처리 방식** — 현재 구조는 **선택한 날짜 하루치만 재생**.

만약 전날 차단이 다음 날로 이어지는 경우 반영하려면:
→ `_scan_data_dates` 수정해서 선택 날짜 + 이전 날짜들 연결 필요 (별도 요청 시 제공)
