## 무엇인가

**AI Agent Chatbot** 메뉴는 사용자가 **자연어로** AMHS 운영 현황과 이상 정보를
조회할 수 있게 하는 **대화형 기능**이다.

반복적인 정보 조회를 간소화하고, 필요한 운영 정보를 빠르게 확인하도록 돕는다.

메뉴를 하나씩 열어 찾는 대신 **말로 묻는 길**이다.
어느 화면에 있는지 모를 때 여기서 먼저 물어도 된다.

## 질의 예시 (가이드 원문)

- "현재 이천 Site 의 주요 이상 현황을 알려줘."
- "M14-M16 Bridge Queue 상태를 확인해줘."
- "오늘 발생한 통신 이상 Alarm 을 요약해줘."

세 예시가 각각 어느 화면과 짝인지:

| 질의 | 대응 화면 |
|---|---|
| 이천 Site 주요 이상 현황 | Site 모니터링 |
| M14-M16 Bridge Queue 상태 | Bridge 모니터링 |
| 오늘 발생한 통신 이상 Alarm | MES-MCS-MCP 통신 이상 감지 · Alarm 발생 이력 |

## 가이드에 안 적힌 것

지원하는 질의의 범위, 답변 근거를 어디서 가져오는지, 대화 이력이 남는지는
USER GUIDE 에 없다. 물으면 **없다고 말한다**.
