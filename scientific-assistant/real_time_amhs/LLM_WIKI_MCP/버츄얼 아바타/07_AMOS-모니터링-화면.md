## 여섯 화면

### Site 모니터링

**이천 Site** 에 대한 AMHS 이상 현황을 통합적으로 보여 준다.
Site 전체 운영 상태와 주요 이상 발생 현황을 빠르게 확인한다.

가장 넓게 보는 화면이다. 여기서 시작한다.

### Layout 모니터링

**FAB Layout 을 기반으로** VHL 이동 현황과 **구간별** 이상 상태를 본다.
실제 Layout 과 연계돼서, 이상이 **어디서** 났고 반송이 어떻게 흐르는지를
그림 위에서 바로 본다.

→ 장치·구간 이름의 뜻은 [[반송 장치 종류와 역할]] 참고.

### Bridge 모니터링

**M14–M16 간** 반송 이동 현황을 본다.
Bridge **Conveyor** · **Lifter** 등 주요 반송 장비와 **Queue** 현황을 확인한다.

→ 이 구간의 구조는 [[M16 HUBROOM 개요]] · [[FAB 간 연결 경로]] 참고.

### Custom 모니터링

원하는 데이터를 **직접 골라** 화면을 구성한다.
업무 목적과 역할에 따라 필요한 정보만 모아 놓을 수 있다.

### FAB 모니터링

**FAB 단위**의 AMHS 운영 상태와 주요 이상 현황을 종합적으로 본다.

### FAB 상세 모니터링

선택한 FAB 의 **장비 · 구간 · 이상 상태**를 상세하게 조회한다.

## 보는 순서 (가이드의 사용 Tip)

> Site 또는 FAB 단위의 **전체 현황을 먼저** 확인한 뒤,
> Layout · Bridge · FAB 상세로 이동하면
> **이상 발생 위치와 영향 범위**를 효율적으로 추적할 수 있다.

```
Site 모니터링 ─┐
               ├→ Layout 모니터링 (구간) ─┐
FAB 모니터링 ─┘                            ├→ FAB 상세 모니터링
               └→ Bridge 모니터링 (M14–M16)┘
```

넓은 데서 좁은 데로 간다. 반대로 가면 이상이 어디까지 번졌는지를 못 본다.

## 가이드에 안 적힌 것

USER GUIDE 는 **각 화면이 무엇을 보여 주는가**까지만 적혀 있다.
화면의 항목 이름 · 임계값 · 색 기준 · 갱신 주기는 문서에 없다.
그것을 물으면 **없다고 말한다** — 짐작해서 답하지 않는다.
