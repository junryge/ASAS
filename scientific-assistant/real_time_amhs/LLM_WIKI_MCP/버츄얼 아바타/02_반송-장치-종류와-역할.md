## 개요

FOUP이 이동하면서 **경유하는 반송 장치**들이다. 각 장치가 무엇을 하는지
알아야 [[FAB 간 연결 경로]] 의 경로가 읽힌다.

## 핵심 용어 정의

- **VHL**: FOUP을 레일을 통해 이동하는 장치. 각 장치 Port에서 FOUP을
  load하거나, 각 장치 port로 FOUP을 unload한다.
- **OHT**: VHL을 제어하는 주체 / 시스템.
- **LFT**: 리프터. **ZT**라고도 불림. FOUP의 **층간 반송**을 담당.
  FOUP이 input port에 위치하면 rack master를 활용해 목적지 output port로 이동.
- **CNV**: 컨베이어. FOUP이 input port에 위치하면 목적지 output port로 이동.
- **STK**: 스토커. FOUP **임시 저장**.
- **STB**: FOUP 임시저장. **ZFS**라고도 불림.
- **Sorter**: **FOSB ↔ FOUP 변환 장치**. Wafer가 입고되면 FOUP의 형태로
  dumping되어 반송을 거치며 각 장비에서 공정 시작.
  **대기Q가 많으면 그만큼 반송해야 할 양이 많다는 방증.**
- **MLUD**: **FIO**라고도 불림. 사람이 Manual Input에 FOUP을 위치시키면
  Auto Output으로 이동해 OHT가 load하거나, OHT가 Auto Input에 위치시키면
  Manual Output으로 이동해 사람이 get할 수 있도록 하는 장치.

## 포트 규칙

**LFT / CNV / Sorter / MLUD**
FOUP 기준으로 **input port로 들어가서 output port로 나온다.**
port는 **Manual / Auto** × **Input / Output** 으로 나뉜다. 따라서 4가지가 가능하다.

| 약칭 | 뜻 |
|---|---|
| **MI** | Manual Input |
| **MO** | Manual Output |
| **AI** | Auto Input |
| **AO** | Auto Output |

**STK / STB**
FOUP이 input port에 위치하면 **rack master에 의해 shelf에 저장**되고,
**호출 시에 다시 output port에 위치**한다.

> port는 **사람 / 시스템에 의해 활성화·비활성화** 될 수 있다.
> 포트가 죽어 있으면 경로가 살아 있어도 FOUP이 못 지나간다 — 정체를 볼 때
> 먼저 확인할 것.
