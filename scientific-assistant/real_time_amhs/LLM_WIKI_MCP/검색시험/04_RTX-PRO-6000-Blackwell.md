> ★**먼저 바로잡을 것 — 이 카드에는 HBM 이 안 들어간다.**
> 이름 안의 **D7 이 GDDR7** 을 뜻한다. 국내 유통에서 메모리 종류를
> D5(GDDR5)·D6(GDDR6)·D7(GDDR7) 로 적는 관행에서 온 표기다.
> HBM 은 데이터센터 가속기(B200·GB200 같은 것)에 들어가고,
> 워크스테이션 RTX 카드에는 안 들어간다.

# RTX PRO 6000 Blackwell MAX-Q 워크스테이션 에디션 D7 96GB (서린)

## 이름 뜯어보기

긴 이름이지만 조각마다 뜻이 있다. 앞에서부터 **누가 만들었나 → 무슨 급인가
→ 어떤 판인가 → 메모리 → 용량 → 누가 파나** 순이다.

| 조각 | 뜻 | 확실한가 |
|---|---|---|
| RTX PRO | NVIDIA 의 **전문가용(프로) 라인** 이름. 예전 Quadro 자리 | 확실 |
| 6000 | 그 라인의 최상급 번호 | 확실 |
| Blackwell | 아키텍처 세대 이름 (RTX 50 과 같은 세대) | 확실 |
| **MAX-Q** | **전력을 낮춘 판.** 같은 칩을 낮은 소비전력으로 돌린다 | 확실 |
| 워크스테이션 에디션 | 데스크톱 워크스테이션에 꽂는 판 (서버용과 구분) | 확실 |
| **D7** | **GDDR7** 메모리. HBM 아님 | 확실 |
| 96GB | 메모리 용량. ECC 지원 | 확실 |
| **서린** | **서린씨앤아이** — 국내 유통사. 만든 곳이 아니다 | 확실 |

## 메모리는 어디서 만드나

묻고 싶으신 게 이거일 텐데, 답이 둘로 갈린다.

**HBM 은 안 들어간다.** 그러니 "이 카드의 HBM 을 어디서 만들었나" 는
답이 없는 질문이다.

**GDDR7 은 들어간다.** GDDR7 을 만드는 곳은 셋이다 —
**SK하이닉스 · 삼성전자 · 마이크론**. 다만 **어느 카드에 누구 것이 붙었는지는
겉으로 알 수 없다.** 같은 모델이라도 생산 시기에 따라 다른 회사 칩이 붙는다.

알아보려면 카드를 열어 **메모리 칩 각인**을 봐야 한다:

| 각인 시작 | 만든 곳 |
|---|---|
| `H` | SK하이닉스 |
| `K` | 삼성전자 |
| `MT` / `D8` | 마이크론 |

## 어떻게 만들어지나

카드 한 장이 나오기까지 이 순서를 지난다.

| 단계 | 누가 | 무엇을 |
|---|---|---|
| ① 설계 | NVIDIA | GPU 칩과 보드를 설계한다 |
| ② 칩 생산 | TSMC | GPU 다이를 찍는다 (파운드리) |
| ③ 메모리 | SK하이닉스 · 삼성 · 마이크론 | GDDR7 칩을 만든다 |
| ④ 패키징 | OSAT | GPU 다이를 기판에 얹는다 |
| ⑤ 보드 조립 | ODM (위탁 제조사) | 기판에 GPU·메모리·전원부·쿨러를 붙인다 |
| ⑥ 유통 | **서린씨앤아이** | 국내에 들여와 판다 |

**프로 라인은 그래픽카드 회사(MSI·기가바이트 같은)가 자기 디자인으로 만들지
않는다.** NVIDIA 설계 그대로 위탁 생산되고, 겉모습도 한 가지다.
그래서 '서린' 은 **만든 곳이 아니라 파는 곳**이다.

★⑤ 의 구체적인 위탁 제조사 이름은 이 위키에 확인된 자료가 없다.

## 누가 이걸 만들게 했나

**NVIDIA 다.** 설계·검증·출시를 NVIDIA 가 한다.
서린씨앤아이는 국내 총판으로, 수입·유통·A/S 를 맡는다. 제작 주체가 아니다.

## 가격

**이 위키에 확인된 가격 자료가 없다.**
프로 라인은 시기·환율·계약 조건에 따라 크게 달라져서, 숫자를 적어 두면
금방 틀린 값이 된다. 견적은 서린씨앤아이나 총판 대리점에 물어야 한다.

★누가 가격을 물으면 **숫자를 지어내지 말고 "확인된 자료가 없다"** 고 한다.

## 무엇을 할 수 있나

**96GB 라는 것이 핵심이다.** 일반 게이밍 카드(RTX 5090 32GB)로는 메모리가
모자라 아예 못 올리는 것을 올릴 수 있다.

- **큰 LLM 을 한 장에** — 카드 여러 장에 쪼개 얹지 않아도 되는 크기가 는다
- **모델 미세조정(파인튜닝)** — 학습은 메모리를 훨씬 많이 먹는다
- **대용량 3D·시뮬레이션** — 장면이 통째로 메모리에 들어가야 하는 작업
- **영상 편집·렌더링** — 고해상도 다중 트랙
- **ECC** — 메모리 오류를 잡아낸다. 오래 돌리는 계산에서 중요하다

## MAX-Q 는 왜 쓰나

같은 칩을 **전력을 낮춰** 돌리는 판이다. 성능은 조금 손해를 보지만:

- 일반 워크스테이션 전원·발열로 감당된다
- 한 대에 **여러 장** 꽂기 쉽다
- 소음이 적다

책상 옆에 두고 쓰거나 카드를 여러 장 넣을 때 고른다.

## 시험 질문

| 물어볼 것 | 맞는 답 |
|---|---|
| 이 카드에 HBM 들어가? | **안 들어간다. GDDR7 이다** |
| D7 이 무슨 뜻이야? | GDDR7 |
| 서린이 만든 거야? | 아니다 — 국내 유통사다. 만든 건 NVIDIA |
| 메모리 어디 거야? | SK하이닉스·삼성·마이크론 중 하나. 칩 각인으로 봐야 안다 |
| GPU 칩은 어디서 만들어? | TSMC |
| 가격 얼마야? | **확인된 자료가 없다** (숫자를 말하면 지어낸 것) |
| MAX-Q 가 뭐야? | 전력을 낮춘 판 |
| 뭘 할 수 있어? | 96GB 라 큰 모델·파인튜닝·대용량 3D |

★**첫 줄과 가격 줄이 이 문서의 핵심이다.**
HBM 이라고 답하거나 가격을 숫자로 말하면 지어낸 것이다.
