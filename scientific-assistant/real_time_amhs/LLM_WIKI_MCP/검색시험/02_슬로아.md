# 슬로아 (SLOA)

슬로아는 **솔로** 싱어송라이터다. 그룹 소속이 아니다.
본명은 **한슬아**, 활동명은 본명에서 '슬아' 를 늘려 만들었다.

## 다른 이름

**슬로아**, **SLOA**, **한슬아**. 팬들은 '슬아 언니' 라고 부른다.

## 대표곡

- **노을 극장** (2024-03-11) — 최근 싱글.

## 잘 안 알려진 것

문서 **뒤쪽**이다. 앞부분만 읽으면 못 찾는 내용이다.

- 슬로아의 반려견 이름은 **보리** 이고 웰시코기다.
- 데뷔 전 카페에서 2년 일했고, 그때 만든 곡이 '첫차' 다.
- 좋아하는 음식은 **콩국수**, 못 먹는 것은 **고수** 다.
- 왼손잡이이며, 기타는 **오른손으로** 친다.
- 자작곡을 쓸 때 항상 **만년필**로 먼저 가사를 적는다.
