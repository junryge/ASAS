# 위키를 서윤이에게 물려주기 (LLM_WIKI_MCP → 아바타)

담당 **버츄얼 아바타**에 올린 M16 HUBROOM 반송 지식을, 서윤이가 대화 중에
직접 찾아 읽게 하는 길이다. 관제 수치로는 답이 안 나오는 것들이 여기 있다 —
"LFT 가 뭐야", "M14 에서 M16 으로 어떻게 넘어가", "Sorter 대기Q 가 왜 중요해".

## ★먼저 — 위키는 프로세스가 **둘**이다

여기서 한 번 헛짚었다. 둘은 **다른 것**이다.

| | 무엇 | 기본 포트 | 누가 쓰나 |
|---|---|---|---|
| `app.py` | Flask 웹앱 | **8100** | 사람이 브라우저로 본다 |
| `mcp_server.py` | FastMCP · MCP | **8020** | **서윤이 붙는다** |

아바타에 넣을 주소는 **8020 쪽**이다. 웹앱 주소(8100)를 넣으면 그쪽에
`/mcp` 가 없어서 Flask 가 HTML 404 를 돌려준다:

```
못 붙었습니다 — 서버가 끊겼다 (HTTP 404 <!doctype html> … 404 Not Found …)
```

**HTML 이 오면 그 주소가 아닌 것이다.** MCP 서버는 JSON 만 준다.
지금은 화면이 그걸 알아보고 이렇게 말해 준다:

> 이 주소는 MCP 서버가 아닙니다 (HTML 404 가 왔습니다). 위키는 프로세스가
> 둘입니다 — 웹앱(app.py · 기본 :8100)과 MCP 서버(mcp_server.py · 기본
> :8020)는 다른 것입니다.

## 왜 따로 띄워야 하나

요청이력(QA)과 위키는 **붙는 방식이 다르다.**

| | QA 요청이력 | AMHS 위키 |
|---|---|---|
| 서버 | `qa/mcp_server.py` (직접 짬, 표준 라이브러리) | `LLM_WIKI_MCP/amhs-llm-wiki/mcp_server.py` (공식 SDK) |
| transport | stdio | **streamable-http** |
| 누가 띄우나 | 아바타가 질문에 걸릴 때 자식 프로세스로 | **사람이 미리** |
| 주소 | (프로세스라 없음) | `http://<주소>:8020/mcp` |

위키 쪽은 FastMCP 로 짜여 있어 자식 프로세스로 못 띄운다. `mcp`·`flask`·
`pypdf` 를 끌고 오기 때문에 아바타와 한 프로세스에 넣을 수도 없다.
**그쪽은 그쪽대로 띄우고, 아바타는 붙기만 한다.**

## 순서

### 1. 위키 MCP 서버를 띄운다

```
cd LLM_WIKI_MCP/amhs-llm-wiki
pip install "mcp>=1.27,<2"        # 폐쇄망이면 미리 반입
python mcp_server.py
```

`* LLM-WIKI MCP 서버: http://0.0.0.0:8020/mcp (streamable-http, DB: …/wiki.db)`
가 찍히면 된 것이다. 웹앱(`app.py`)이 꺼져 있어도 DB 를 직접 읽어서 돈다.

포트를 옮기려면 `LLM_WIKI_MCP_PORT` 를 준다 (웹앱 쪽은 `LLM_WIKI_PORT`
— **둘은 다른 변수다**). 옮겼으면 화면(설정 → 외부 도구)에서 주소만
고치면 된다.

### 2. 아바타를 띄운다

같은 PC 면 그냥 띄우면 된다 (기본값이 `http://127.0.0.1:8020/mcp`).

```
cd avatar_2d
python run.py
```

**다른 PC 에 있으면** 주소를 준다 — 코드를 고칠 일이 아니다.

```
python run.py --wiki http://10.125.x.x:8020
```

`/mcp` 를 빼먹어도 붙여 준다. 환경변수 `WIKI_MCP_URL` 로 줘도 같다.

켜질 때 이렇게 찍힌다:

```
  MCP: QA 요청이력 → http://127.0.0.1:10500
  MCP: AMHS 위키 → http://127.0.0.1:8020/mcp  ※위키 쪽에서 mcp_server.py 를 띄워 둬야 붙는다
  MCP 서버 2개 등록 (질문에 걸리면 그때 띄운다)
```

## 화면에서 켜고 끄기 (설정 → 외부 도구)

아바타 **설정** 탭에 `외부 도구 (MCP)` 칸이 있다. 여기서 다 된다.

| 하는 것 | 어떻게 |
|---|---|
| 켜기 / 끄기 | 왼쪽 체크박스 |
| 주소 고치기 | 칸에 적고 `주소 적용` (`/mcp` 는 빼먹어도 붙여 준다) |
| 지금 붙었나 | 초록 점 = 붙음 · 빨간 점 = 못 붙음 · 회색 = 꺼짐 |
| 다시 붙기 | `전부 다시 붙기` |

**안 떠 있는 서버는 끄는 게 낫다.** 켜 두면 물어볼 때마다 붙으러 갔다가
실패해서 답이 느려진다. 여기서 끈 것은 서버(`data/settings.json`)에
저장되어 **재시작해도 그대로**다.

> 한 번 못 붙은 서버는 30초 쉬었다 다시 시도한다. 그동안은 두들기지 않고
> 바로 "못 붙었다" 고 답한다 — 안 그러면 대화가 매번 멎는다.
> `전부 다시 붙기` 를 누르면 그 30초를 건너뛴다.

## 무엇을 물으면 위키를 보나

낱말이 걸려야 본다. **평소 관제 대화에서는 안 뜬다** — 뜨면 그게 곧 비용이다.

**걸리는 것**
`HUBROOM` · `허브룸` · `Bridge` · `VHL` · `LFT` · `CNV` · `STK` · `STB` ·
`Sorter` · `소터` · `MLUD` · `FOUP` · `FOSB` · `ZFS` · `FIO` · `리프터` ·
`컨베이어` · `스토커` · `층간` · `연결 경로` · `경유` · `위키`

**뜻을 물을 때만 걸리는 것** — `OHT` · `반송` · `포트`
뒤에 `뭐/무엇/뜻/의미/역할/차이/설명/구분` 이 붙어야 한다.

> "M14 **반송**시간 알려줘" 는 관제 질문이다. `반송` 을 그냥 낱말로 두면
> 이런 질문마다 위키를 뒤진다 — 시험이 실제로 잡아서 뺐다.

**안 걸리는 것** — "M16HUB 지금 몇 점이야?", "M14 반송시간 알려줘",
"지금 상태 어때", "M14 반송 어떻게 되고 있어?"

## 무엇을 읽나

한 번 걸리면 도구가 **최대 3번** 돈다.

```
searchWiki(query=질문 그대로, topK=4)     ← 어느 쪽인지 찾는다
  → readPage(pageId=…)  ×2               ← 찾은 쪽의 본문을 읽는다
```

조각(500자)만 주면 앞머리만 아는 상태가 된다 — 요청이력에서 그대로 겪은
일이다("하기는 잘해.. 근데 상세한 내용을 물어보면 몰라"). 그래서 **검색에서
끝내지 않고 본문까지** 읽는다.

한 조각당 2500자까지만 싣는다. 넘으면 `…(뒤가 잘렸다 · 전체 N자)` 가 붙고,
서윤은 그 뒤를 아는 척하지 말라는 지시를 같이 받는다.

**읽기만 한다.** 페이지 생성·수정·삭제 도구는 부르지 않는다.

## 안 될 때

| 화면/콘솔 | 뜻 | 할 일 |
|---|---|---|
| `MCP 걸렸는데 결과 없음 (AMHS 위키 서버 확인)` | 안 떠 있거나 주소가 다르다 | 1번을 다시 하고 주소를 확인 |
| 서윤이 "위키를 확인할 수 없다" | 위와 같다 | 위와 같다 |
| `HTTP 404 <!doctype html>` | **웹앱 주소(8100)를 넣었다** | `mcp_server.py` 를 띄우고 **8020** 을 넣기 |
| 붙기는 하는데 답이 빈다 | 옛 아바타다 (SSE 를 못 읽던 것) | `mcp_client.py` 를 최신으로 |
| `HTTP 406` | `Accept` 에 `text/event-stream` 이 없다 | 위와 같다 |

혼자 재 보려면:

```
curl -s -X POST http://127.0.0.1:8020/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"x","version":"1"}}}'
```

`serverInfo` 에 `llm-wiki` 가 보이면 서버는 멀쩡한 것이다.

## 서윤이 위키를 어떻게 다루나

프롬프트에 이 세 줄이 같이 들어간다.

- **[AMHS 위키] 는 지식 문서다. 지금 수치가 아니다** — 위키에 적힌 숫자를
  현재 값으로 말하면 안 된다.
- 용어·구조·경로를 물으면 이 내용으로 답한다. **위키에 없는 것은 없다고**
  말한다.
- 본문이 `뒤가 잘렸다` 로 끝나면 그 뒤는 못 본 것이다.

요청이력 규칙("여기 적힌 건수는 요청 접수 건수다", "총 건수와 아직 안 끝난
것을 반드시 말한다")은 **위키 결과에는 안 붙는다.** 한 블록에 규칙을 다
쏟으면 서윤이 위키 페이지를 놓고 건수를 세려 든다.
