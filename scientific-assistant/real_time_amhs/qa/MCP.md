# 요청/응답 관리 ↔ 서윤 (MCP)

`qa/app.py` (요청/응답 관리)를 서윤(avatar_2d)이 볼 수 있게 MCP 로 연결한다.

## 왜 공식 SDK 를 안 쓰나

폐쇄망이다. 공식 `mcp` SDK 는 pydantic·starlette·uvicorn·cryptography 등
**30개 남짓**을 끌고 온다. 이 프로젝트는 원래 "단일 파일 · pip only ·
CDN 없음" 전제로 만들어져 있어 그걸 다 넣을 수 없다.

MCP 는 실체가 **JSON-RPC 2.0** 이라 표준 라이브러리만으로 짜진다. 그래서
직접 짰고, 규격이 맞는지는 **망 열린 곳에서 공식 SDK 로 양방향 확인**했다.

| 확인한 것 | 결과 |
|---|---|
| 우리 서버 ↔ 공식 SDK 클라이언트 | 악수 · tools/list · tools/call · 오류처리 통과 |
| 우리 클라이언트 ↔ 공식 SDK 서버 | 같은 항목 통과 |

들어가는 파일은 둘뿐이고 **바깥 패키지를 하나도 안 쓴다** (`tests/test_mcp.py`
의 `stdlib_밖을_안_쓴다` 가 못 박는다).

| 파일 | 하는 일 |
|---|---|
| `qa/mcp_server.py` | 요청관리를 MCP 로 연다 (조회 4종) |
| `avatar_2d/avatar/mcp_client.py` | 서윤이 붙는 쪽 (`Client` · `Hub`) |

## 읽기 전용이다

등록·수정·삭제·상태변경은 **일부러 안 연다**. 서윤이 사람 대신 요청을
지우거나 상태를 바꾸면 이력 관리의 의미가 없어진다.

| 도구 | 준다 |
|---|---|
| `qa_meta` | 총건수·미결·확인완료·상태별·대상·사람 |
| `qa_items` | 조건 검색 (말·상태·구분·대상·요청자·확인여부·기간) |
| `qa_item` | 한 건을 응답·첨부까지 펼쳐서 |
| `qa_history` | 한 건의 변경 이력 |

## 언제 도나

`avatar_2d/avatar/config.py` 의 `MCP_SERVERS[].when` 에 적힌 말이 질문에
있을 때만 뜬다. 관제 질문("M16HUB 몇 점이야?")에는 **프로세스가 아예 안
생긴다** — 평소 비용 0.

```
질문 "M16HUB 개선요청 뭐 있어?"
  → when 에 '개선요청' 이 걸림
  → qa/mcp_server.py 를 stdio 로 띄움 (한 번 띄우면 살려 두고 다시 씀)
  → qa_meta + qa_items(target=M16HUB) 호출
  → 프롬프트의 [외부 도구 — MCP] 칸에 실림
```

### 목록은 항상 준다

`calls[].pick_opt` — 질문에 단서가 있으면 좁히고, **없으면 최근 것부터** 준다.

| 물어보면 | 좁히는 것 |
|---|---|
| "요청 뭐 올라와 있어?" | 안 좁힘 — 최근 20건 |
| "보류된 요청 뭐야" | 상태 = 보류 |
| "M16HUB 개선요청" | 대상 = M16HUB |
| "김윤환TL님 요청" | 검색어 = 김윤환TL |
| "AVGTOTALTIME1MIN 왜 썼어?" | 검색어 = AVGTOTALTIME1MIN |
| "R-A룰 왜 바꿨어" | 검색어 = R-A |

★예전엔 이걸 `pick`(필수)로 뒀다. 등록된 요청의 **대상이 전부 `ALL`** 이라
FAB 이름으로만 좁히게 해 놨더니 **목록이 한 번도 안 나왔다** — "총 5건" 만
말하고 그 5건이 뭔지는 못 말했다. 그래서 `pick_opt` 를 만들었다.

`calls[].pick` (필수)은 상세 조회에만 쓴다 — "#2", "No.2" 로 번호를 못 뽑으면
엉뚱한 건을 펼치느니 건너뛴다.

### 낱말이 없어도 걸리는 경우

`when` 의 낱말이 하나도 없어도, 질문에 **컬럼·룰 이름**이 있으면 본다
(`when_re`). "AVGTOTALTIME1MIN 왜 썼어?" 의 답이 보류 건에 그대로 있는데
'요청' 이라는 말이 없다고 안 걸려서 못 찾아 줬다.

맨 FAB 이름(`M16HUB`·`M14`·`ALL`)은 **코드로 안 본다** — 그러면 "M16HUB 지금
몇 점이야?" 같은 관제 질문마다 요청이력을 뒤진다. 밑줄·점이 있거나 아주 긴
것만 코드로 친다.

## 왜 [관제 근거] 에 안 섞나

`[관제 근거]` 블록에는 "대답 첫머리에 **데이터 시각**을 말하라" 가 붙어
있다. 요청이력을 거기 넣으면 서윤이

> "2026-08-26 04:20 데이터 기준으로 개선요청이…"

라고 시작한다 — 관제 시각으로 요청이력을 말하는 셈이다. 첨부 파일에서
이미 똑같이 겪었다. 그래서 `[외부 도구 — MCP]` 로 따로 세우고 "관제 실측이
아니다 · 데이터 시각을 앞세우지 마라" 를 붙였다.

컨텍스트 사용량 화면에도 `외부 도구 (MCP)` 칸이 따로 있다. 칸이 없으면
실려 있는데도 화면 합계에서 빠져 보인다 (참고자료 MD 때 겪은 그 증상).

## 띄우기

요청관리 앱이 먼저 떠 있어야 한다.

```
cd qa
pip install flask openpyxl
python app.py                 # http://<서버IP>:10500
```

서윤은 `run.py` 로 띄우면 알아서 잡는다. 주소가 다르면
`config.MCP_SERVERS[0]["env"]["QA_BASE"]` 를 고친다.

MCP 서버를 손으로 확인하려면:

```
echo '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | python qa/mcp_server.py
```

## 안 될 때

| 증상 | 볼 곳 |
|---|---|
| 서윤이 요청이력을 아예 모른다 | 질문에 `when` 의 말이 있나 |
| "붙지 못했다" 라고 한다 | `qa/app.py` 가 떠 있나 · `QA_BASE` 주소 |
| 값이 비어 있다 | 요청관리 DB(`qa/reqlog.db`)에 데이터가 있나 |
| 조용히 아무것도 안 나온다 | `calls[].tool` 이름 오타 (시험이 잡는다) |

MCP 가 죽어도 **대화는 이어진다** — 실패는 글로 적어 넘기고, 무엇이 터지든
삼킨다. 외부 도구 하나 때문에 서윤이 입을 닫으면 안 된다.
