# 2D 감정캐릭터 × LLM — 파이썬 중심 구조

## ★버추얼 관제 에이전트 (v30)

이 앱은 이제 **real_time_amhs 관제 데이터를 직접 보는 에이전트**다.

- **실데이터 알람** — 관제 서버(기본 `http://127.0.0.1:8989`, `--sentinel` 로 변경)의
  ALL + FAB 5 등급을 5초마다 읽어 **경계/위험/초위험**이면 자동으로 알람을 울린다.
  정상 복귀 후 **60분 관찰 유지**(관제의 '사건 60분 뒤 닫힘' 과 같은 규칙) —
  재발하면 다시 울리고, 조용히 넘어가면 자동 해제. 관제가 끊기면 **끊겼다고 말한다.**
- **알람 이력** — 서버가 `data/alarms.json` 에 기억한다. `/알람기록` 또는 `/api/alarms`.
- **근거 우선 대화** — 데이터 질문이면 실측값을 먼저 계산해 프롬프트에 넣고,
  **대답의 숫자가 근거에 없으면 그 답을 버리고 실측 요약으로 바꾼다** (숫자 가드).
  데이터가 오래됐으면(10분+) 오래됐다고 밝힌다.
- **채팅 명령** (LLM 을 안 거치는 결정적 경로):
  `/상태` `/진단` `/알람기록` `/스킬 목록` `/스킬 보기 <이름>`
  `/스킬 만들기 <이름> [주제]` `/스킬 삭제 <이름>` `/도움말`
- **스킬** — 데모스 SKILL.md 형식 그대로 (`data/skills/<이름>/SKILL.md`).
  `/스킬 만들기` 가 최근 대화+근거에서 초안을 만들어 검증 후 저장한다.
  md 전문은 자르지 않고 그대로: `/api/skills/md?name=` · html: `/api/skills/html?name=`.
  실행하면 `fab-score` 스킬(FAB별 위험도 스코어 문서)이 자동으로 심어진다.
  여기서 만든 스킬 폴더는 데모스 `scientific-skills/` 에 그대로 복사해도 돌아간다.
- **📎 채팅 첨부** — 입력창 옆 클립. 올린 파일은 다음 질문의 최우선 근거 + 자료함에 저장.
- **응답창 마크다운** — 표·코드·제목이 렌더링된다. 말풍선은 걷어낸 요약만 말한다.
- **미니 모드** — `미니` 칩: 패널 숨김. `소형창` 칩: 화면 우하단 작은 창(430×580)으로 새로 띄움.
- **세션 공유** — 세션은 서버 병합 저장이라 **다른 PC 에서 같은 서버로 접속하면 같은
  목록**이 보인다 (서버를 PC 마다 따로 띄우면 당연히 따로다). ⤓ 버튼이 JSON + MD +
  **HTML**(그대로 공유 가능한 단독 파일)을 내려받는다. `/api/sessions/html?id=`.
- **SD 러너** — ☰/◧ 접기·펼치기를 누르면 꼬마 캐릭터가 후다닥 달려와 버튼을 누르고
  지나간다. 그림을 바꾸려면 초록 배경 그대로 `static/assets/sd_run.png` 로 저장
  (서버가 알아서 투명 처리). 없으면 내장 꼬마로 동작. 속도는 콘솔에서
  `window.SD_DUR=600` (작을수록 빠름, 기본 850ms).


평면 이미지 1장을 WebGL 메쉬로 실시간 변형해서 표정·손동작을 만들고,
LLM 응답에 감정/모션을 붙여 움직이는 앱.

**v29 부터 파이썬이 앱의 중심이다.** 브라우저는 렌더링(WebGL)과 화면만 담당하고,
프롬프트 조립·자료 검색·세션 보관·설정은 전부 파이썬 서버가 한다.

```
run.py                 ← 실행 진입점. python run.py
avatar/                ← 파이썬 패키지 (앱 로직의 중심)
  config.py              스케줄·FAB·알람 등급·의상·배경·사원증 등 모든 설정
  llm.py                 프롬프트 조립 · response_format 3단계 폴백 · 스트리밍 파싱
  docs.py                참고 자료 보관 + 질의어 검색 주입 + 토큰 추정
  sessions.py            세션 보관 (서버 디스크)
  settings.py            서버측 설정 (자료 예산 등)
  server.py              HTTP 서버 (static/ + /api/* + /v1 프록시)
static/                ← 브라우저 쪽 (화면·렌더링만)
  index.html             화면 구조
  app.css                스타일
  app.js                 WebGL 렌더링 + UI (LLM 호출은 /api/chat 뿐)
  assets/                그림 파일 (의상 5, 배경 5, FAB 3, 로고) — HTML 과 분리
data/                  ← 실행하면 생긴다 (서버 저장소)
  settings.json          자료 예산·컨텍스트 한도·대화 기록 수
  sessions.json          세션 (최근 30개 / 1.2MB — 서버가 강제)
  docs.json              참고 자료 본문
token.txt              ← 직접 넣어야 함. 토큰 한 줄만. (절대 배포물에 포함 금지)
```

무엇을 바꾸고 싶으면 어디를 고치나:

| 바꿀 것 | 파일 |
|---|---|
| 시간표·배경·의상·사원증·FAB·알람 등급·대사 | `avatar/config.py` |
| 프롬프트 규칙·폴백·스트리밍 | `avatar/llm.py` |
| 자료 검색 방식 | `avatar/docs.py` |
| 화면·애니메이션·셰이더 | `static/app.js` |
| 그림 교체 | `static/assets/` 에 같은 이름으로 |

## 1. 실행

`token.txt` 를 `run.py` 와 같은 폴더에 두고,

```bash
python run.py
```

엔드포인트(HCP 운영/개발/Common/OpenAI/직접 입력) → `/v1/models` 모델 목록 →
번호 선택. 브라우저가 자동으로 열리고 **앱 설정도 자동으로 채워진다.**

```bash
python run.py --upstream http://hcp.llm.skhynix.com --model Qwen3-32B   # 선택 생략
python run.py --token-file D:/keys/token.txt                            # 토큰 위치 지정
python run.py --port 8686                                               # 포트 변경
python run.py --local-only                                              # 외부 접속 차단
python run.py --no-browser
```

기본으로 **`0.0.0.0:8585`** 에 바인드된다. 같은 망의 다른 PC 에서
`http://<이 컴퓨터 IP>:8585/` 로 접속하면 되고, 실행하면 터미널에 주소가 찍힌다.
안 되면 윈도우 방화벽에서 python.exe 의 해당 포트 인바운드를 허용해야 한다.

> Python 3.8+ / 표준 라이브러리만. 설치할 것 없음.

## 2. 동작 방식 (파이썬이 하는 일)

브라우저는 `/api/chat` 에 `{text, persona, history}` 만 보낸다. 파이썬이

1. **자료 검색** — `data/docs.json` 에서 질문과 겹치는 문단을 예산만큼 골라
2. **프롬프트 조립** — 페르소나 + 자료 + 출력 규칙 + 최근 대화
3. **게이트웨이 호출** — `response_format` 3단계 폴백
   (`json_schema` → `json_object` → 없음)
4. **스트리밍 파싱** — upstream SSE 의 미완성 JSON 을 부분 파싱해서
   브라우저에는 **이미 해석된 이벤트**로 재방출한다

```
data: {"emo": {"emotion":"joy","intensity":0.9,"motion":"wave"}}   ← 표정이 먼저
data: {"text": "안녕하세요. 오늘 물류…"}                            ← 대사(누적)
data: {"final": {...}}                                              ← 완성본
```

그래서 말이 시작되기 전에 표정이 잡히고, 브라우저 쪽엔 JSON 파서가 없다.

- 토큰은 `run.py` 프로세스에만 있고 **브라우저에는 안 남는다**
- 사내 주소(`*.skhynix.com`)는 시스템 프록시를 자동 우회, 자체서명 인증서 통과
- 같은 출처라 CORS 문제 없음. `/v1/*` 원시 프록시도 그대로 있다 (모델 목록 등)
- 터미널 로그: `200  /api/chat  Qwen3-32B  842ms  (stream, 46이벤트)`

| 코드 | 원인 |
|---|---|
| `401` `403` | 토큰 만료/오류 → token.txt 확인 |
| `404` | 모델 이름 또는 엔드포인트 오류 |
| `429` | 사용량 한도 초과 |
| `연결 실패` | 사내망/VPN 미연결 |

## 3. 세션 · 자료 · 설정 — 서버에 저장된다

- **세션** — `data/sessions.json`. 브라우저가 아니라 서버에 있으므로
  **다른 PC 에서 접속해도 같은 목록**이 보인다. 최근 30개/1.2MB 는 서버가 강제.
  대화 탭 상단: 드롭다운(지난 세션 열기·이어서 대화) · ＋(새 세션) ·
  ⤓(JSON+Markdown 다운로드) · ✕(삭제). AI 답변을 클릭하면 그때 표정으로 다시 재생.
- **참고 자료(MD/TXT)** — `data/docs.json`. `자료` 칩·설정 탭·드래그&드롭으로 추가.
  예산(기본 6,000자)을 넘으면 **질문과 겹치는 문단만** 골라 주입한다(`avatar/docs.py`).
- **서버 설정** — `data/settings.json`. 자료 예산·컨텍스트 한도·대화 기록 수·온도.
  설정 탭 슬라이더를 움직이면 자동으로 서버에 반영된다.
- **컨텍스트 사용량** — `/api/ctx` 가 페르소나/자료/규칙/기록/입력을 나눠 추정한다
  (한글 0.72/자, 영숫자 3.6자당 1). 입력창 옆 `ctx n%`, `◧` 패널, 설정 탭 세 곳 표시.
- 캘리브레이션·렌더링 값 등 **화면 설정**은 지금처럼 브라우저(localStorage)에 저장.

## 4. 화면 기능 (전부 그대로)

- **시간표 자동 전환** (우상단 시계 · `avatar/config.py` 의 `SCHEDULE`)

| 시간 | 배경 | 의상 | 사원증 |
|---|---|---|---|
| 07:00–08:30 | 정문 | 가운 | 켜짐 |
| 08:31–10:00 | 공장 | 무진복 | 켜짐 |
| 10:01–11:30 | 회의실 | 정장 | 켜짐 |
| 11:31–13:30 | 정문 | 가운 | 켜짐 |
| 13:31–14:30 | 회의실 | 정장 | 켜짐 |
| 14:31–16:50 | 공장 | 무진복 | 켜짐 |
| 16:51–17:10 | 회의실 | 정장 | 켜짐 |
| 17:11–19:30 | 테라스 | 반팔 | 꺼짐 |
| 19:31–06:59 | 집 | 잠옷 | 꺼짐 |

  자동/수동은 시계 클릭으로 토글. 배경 칩을 직접 누르면 수동이 된다.
  `from > to` 면 자정을 넘는 구간. 정문 배경에는 회사 로고가 합성돼 있다.

- **FAB 알람** (우하단 · `config.py` 의 `FABS`/`LEVELS`) — [테스트] 를 누르면
  **FAB 3개 × 등급 3개(경계/위험/초위험)** 중 하나씩 무작위. 등급색 경광등,
  건물 그림 + FAB 이름, 경고음(WebAudio), 등급별 주기로 재촉 대사,
  위험/초위험이면 **좌우 등속 이동**(경계는 제자리). [해제] 로만 멈춘다.
  실제 알람 소스를 붙이려면 `fireAlarm(FABS[i], LEVELS[j])` 호출.
- **사원증** — 목줄+카드를 캔버스에 직접 그린다. 카드는 2차 스프링으로 한 박자
  늦게 흔들린다. 내용은 `config.py` 의 `BADGE`. `사원증` 칩으로 on/off.
- **궁예 모드** — 안대 + 페르소나 교체. 해제하면 원래 페르소나로.
- **마우스 시선 추적**, **머리카락·옷 관성**, **말풍선(스크롤바 숨김)**,
  **캘리브레이션 핸들**(눈 좌우 따로), **의상 드래그&드롭 추가**, **감정/모션 수동 제어**,
  **한글 IME Enter 보호**, **입력창/사이드바 크기 드래그** — 전부 유지.

## 5. HTML 단독 실행 (데모)

`static/index.html` 을 더블클릭해도 열린다. 서버가 없으므로 LLM 은
**데모 모드**(키워드 규칙)로 동작하고, 자료·서버 세션은 꺼진다.
렌더링·표정·모션 확인용.

## 6. 문제가 생기면

- 화면이 이상하면 설정 탭 **버전**부터 확인 — `v29 · 파이썬 중심 구조` 가 아니면
  브라우저 캐시다. `Ctrl+F5`. (서버가 html/js/css 에 no-store 를 붙이므로 드물다)
- 응답이 안 오면 **run.py 터미널 로그**를 본다. 어느 단계(HTTP 코드)에서
  걸렸는지 그대로 찍힌다.
- `data/` 를 지우면 세션·자료·서버 설정이 초기화된다.
