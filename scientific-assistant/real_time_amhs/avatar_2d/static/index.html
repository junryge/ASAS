LLM 연결 (OpenAI 호환)

키를 넣고 연결 테스트를 누르세요. 성공하면 자동 저장돼서 다음에 열 때 바로 연결됩니다.

run.py 로 실행하면 이 칸들은 자동으로 채워집니다 (토큰은 서버에만 있고 브라우저엔 안 남습니다).
HTML만 단독 실행하면 키가 필요하고, 없으면 데모 모드로 동작합니다.

세션 기록

세션은 브라우저에 저장됩니다(최근 30개). 대화 탭 상단에서 세션을 고르면 그 대화를 다시 보고 이어서 대화할 수 있습니다. ⤓ 는 그 세션을 JSON + Markdown 으로 내려받습니다.

컨텍스트 사용량

토큰 수는 추정치입니다(한글 0.72/자, 영숫자 3.6자당 1). 모델 토크나이저에 따라 ±15% 정도 차이가 납니다.

참고 자료 (MD · TXT)

자료가 예산보다 크면 질문과 관련된 문단만 골라 넣습니다. 작으면 전체를 넣습니다. 예산이 클수록 정확하지만 응답이 느리고 비용이 늘어납니다.

외부 도구 (MCP)

불러오는 중…

서윤이 대화 중에 바깥 시스템을 직접 조회하는 길입니다. 질문에 걸리는 낱말이 있을 때만 돕니다 — 평소 대화에서는 안 뜹니다.
QA 요청이력은 아바타가 알아서 띄웁니다. AMHS 위키는 LLM_WIKI_MCP/amhs-llm-wiki 에서 python mcp_server.py 를 따로 띄워 둬야 붙습니다.
안 떠 있는 서버는 끄는 게 낫습니다 — 켜 두면 물어볼 때마다 붙으러 갔다가 실패해서 답이 느려집니다. 여기서 끈 것은 서버에 저장되어 재시작해도 그대로입니다.

관제 에이전트 규칙 (기본 프롬프트)

페르소나와 별개로 서버가 항상 붙이는 규칙입니다 — 근거 밖 숫자 금지, 데이터 시각 먼저 말하기, 룰 코드 대신 실제 컬럼명, 줄바꿈 등. 무엇을 가르쳤는지 여기서 확인하고 고칠 수 있습니다. 고치면 서버(data/settings.json)에 저장되어 다른 PC 에서도 같이 적용됩니다.
