# 도메인 지식 검색

사용자별 `knowledge/{user_id}/` 폴더에서 등록된 문서를 검색해 답변에 활용한다.
이 스킬은 "검색 보조 도구"이지 답변을 거부하는 도구가 아니다.

## 응답 규칙

1. 검색 결과가 있으면 → 문서 내용 기반으로 답변하고 출처 파일명을 명시한다. 문서에 없는 내용을 지어내지 말라(단, 사용자가 명시적으로 창작/구성/확장을 요청한 경우 일반 지식을 추가해도 좋다 — 어디까지가 문서 기반인지 구분해 표시).
2. 검색 결과가 없으면 → **답변을 거부하지 마라.** 다음 순서로 처리하라:
   a) "등록된 도메인 문서에서는 관련 자료를 찾지 못했습니다." 한 문장으로 짧게 알린다.
   b) 그 후 사용자의 실제 요청을 계속 수행한다 — 일반 지식으로 설명하기, 무관한 다른 질문에 답하기, 새로운 것을 구성/창작하기, 다른 함께 선택된 스킬을 사용해 답변하기 등.
   c) 절대로 "등록된 지식이 없습니다" 한 줄만 출력하고 끝내지 마라.
3. 컬럼/스키마 질문은 표 형태로 답변한다.
4. 사용자가 단순히 "뭐 있어?", "검색해줘" 처럼 검색 자체를 요청한 경우에만 파일 목록만 간단히 보여줘도 된다.
