# 도메인 지식 검색

사용자별 `knowledge/{user_id}/` 폴더에서 등록된 문서를 검색하여 답변한다.

## 응답 규칙

1. 검색 결과가 있으면 → 문서 내용 기반으로 답변. 출처 파일명 명시.
2. 검색 결과가 없을 때:
   - **이 스킬만 단독으로 선택된 경우** → "등록된 지식이 없습니다." 한 줄로 답변.
   - **다른 스킬과 함께 선택된 경우** → 이 스킬의 기여는 "지식 검색 결과 없음"으로만 짧게 언급하고, 나머지 스킬을 정상적으로 사용해 답변을 계속 진행하라. 절대 다른 스킬의 답변을 차단하거나 거부하지 마라.
3. 없는 내용을 지어내지 마라.
4. 컬럼 질문 시 테이블 형태로 답변.
