# MD / HTML 문서 변환 스킬

이 스킬이 활성화되면 시스템이 자동으로 응답을 MD 파일과 HTML 파일로 변환하여 다운로드 링크를 제공합니다.

## 작성 가이드

보고서/문서 품질을 높이기 위해 아래 Markdown 작성 규칙을 따르세요:

### 구조화 규칙

1. **제목 계층**: `#` 대제목 → `##` 섹션 → `###` 소섹션으로 논리적 구조
2. **표**: 데이터 비교·요약에는 반드시 Markdown 표 사용
3. **목록**: 핵심 포인트는 번호(`1.`) 또는 불릿(`-`) 목록으로 정리
4. **강조**: 핵심 용어는 `**굵게**`, 부가 설명은 `*기울임*`
5. **인용**: 중요 발견/결론은 `>` 인용 블록 활용
6. **코드**: 기술 내용은 `` ``` `` 코드 블록 사용

### 보고서 권장 구성

```
# 보고서 제목

## 1. 개요
배경, 목적, 범위

## 2. 본론
분석 결과, 데이터, 표, 차트 설명

## 3. 핵심 발견사항
> 주요 인사이트를 인용 블록으로

## 4. 결론 및 제언
요약, 권고사항, 향후 과제
```

### 표 작성 예시

```markdown
| 항목 | 수치 | 비고 |
|------|------|------|
| 생산량 | 1,200대 | 전월 대비 +15% |
| 불량률 | 0.3% | 목표 0.5% 이내 달성 |
```

## 지원 기능

| 기능 | 설명 |
|------|------|
| MD 다운로드 | 원본 Markdown 파일 다운로드 |
| HTML 다운로드 | 스타일 적용된 HTML 문서 다운로드 |
| 표 변환 | Markdown 표 → HTML 테이블 자동 변환 |
| 코드 하이라이트 | 코드 블록 구문 강조 |
| 목차 자동 생성 | 제목 기반 TOC 자동 삽입 |

## 주의사항

- 응답 본문에 HTML 태그를 직접 작성하지 마세요. 순수 Markdown만 사용하세요.
- 시스템이 Markdown을 자동으로 HTML로 변환합니다.
- 이미지 URL이 있으면 `![설명](URL)` 형식으로 포함하세요.
