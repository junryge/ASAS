# Chronos-2 모델 다운로드 · 설치 가이드

> 대상: `run_chronos_sentinel.py` / `run_chronos2_covariates.py` 실행 환경 준비
> 모델: **`amazon/chronos-2`** (HuggingFace, https://huggingface.co/amazon/chronos-2)

## 필요한 것 3가지
1. 모델 가중치 — `amazon/chronos-2`
2. 파이썬 패키지 — `chronos-forecasting>=2.0`, `torch`, `pandas`
3. RAM 약 8GB (CPU 기준). GPU면 GPU메모리 ~2GB.

---

## ① 인터넷 되는 서버 — 자동

별도 작업 없음. 코드 첫 실행 시 `from_pretrained("amazon/chronos-2")` 가
`~/.cache/huggingface` 로 자동 다운로드·캐시. 이후 재다운로드 안 함.

```bash
pip install -r requirements.txt
python3 run_chronos_sentinel.py --model amazon/chronos-2 --device cpu \
    --data JUNE.CSV --horizon 10 --threshold 12.0
```

---

## ② 폐쇄망(사내 FAB) — 오프라인

인터넷 PC에서 받아 → USB 복사 → 로컬 경로 지정.

### (A) 모델 가중치
```bash
# [인터넷 PC]
pip install "huggingface_hub[cli]"
huggingface-cli download amazon/chronos-2 --local-dir ./chronos-2
#   → ./chronos-2 폴더를 사내 서버로 복사

# [사내 서버] --model 에 폴더 경로
python3 run_chronos_sentinel.py --model ./chronos-2 --device cpu \
    --data JUNE.CSV --horizon 10 --threshold 12.0
```

### (B) 파이썬 패키지 (오프라인 whl)
```bash
# [인터넷 PC] CPU용 whl 미리 받기
pip download torch chronos-forecasting pandas -d ./wheels
#   → ./wheels 복사 후

# [사내 서버]
pip install --no-index --find-links ./wheels torch chronos-forecasting pandas
```
> GPU 서버면 `pip download` 시 CUDA 빌드 torch 를 받도록 인덱스 지정
> (예: `--extra-index-url https://download.pytorch.org/whl/cu121`).

## 실행 요약

| 상황 | 명령 |
|---|---|
| GPU | `--model amazon/chronos-2`(device 자동 cuda) |
| CPU 실시간 | `--model amazon/chronos-2 --device cpu` |
| CPU 한달 백테스트 | `... --device cpu --stride 5` (가속) |
| 폐쇄망 | `--model ./chronos-2`(로컬 폴더) |
| 초경량 CPU(단변량만) | `--model amazon/chronos-bolt-tiny` |

## 검증 체크
- 모델 로드 성공 시 실행 로그 `예측 backend: chronos-2` 표시.
- `⚠ Chronos 모델 로드 실패 → baseline` 뜨면 패키지/모델 경로 확인.
- covariate 경로(`run_chronos2_covariates.py`)에서 `predict_df` 반환 컬럼명 오류 나면
  그 컬럼명을 확인해 `forecast_with_covariates()` 의 `qcol()` 매칭에 반영.
