모델 Endpoint 호출했을 때, 수동으로 집계되는 모니터링 항목을 잘 만드는 Tip을 드립니다.

1.아래 화면 메뉴 위치: AI Studio Portal > My Project 카드 클릭 > Monitoring > Model > 녹색 카드
2.Predict 함수의 return으로 aiu_monitoring 이름으로 지정된 값만 수집됩니다.
	🔨 return {"aiu_output" : [1, 2, 3], "aiu_monitoring": 1}
3.aiu_monitoring 값에는 Number, 숫자형 String, Single List(개별 Item은 숫자) 타입만 허용됩니다. 이 외 경우는 출력되지 않거나, 평균으로 치환되어 차트에 표시될 수 있습니다.
4.아래 차트에서 Point 한 건은 모델 Endpoint를 호출했을 때의 aiu_monitoing 개별 값입니다.
	(예) aiu_monitroing 값이 1이면 차트에는 Point 1건, aiu_monitroing 값이 [1, 2, 3]이면 차트에는 1, 2, 3 세 건의 Point가 표시됩니다.
