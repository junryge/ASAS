: 전체적으로 어떤 모델과 서비스가 있고 어떤 Run 들이 있는지에 대하여 확인 가능 합니다.



(1) Model : 최근 등록된 모델과 최신 버전을 보여 줍니다.

(2) Endpoint : 최근 등록된 Endpoint 를 보여 줍니다.

(3) Run Template : 최근 등록된 Runb Template을 보여 줍니다.

(4) Run Instance : 최근 실행된 Run 을 보여 줍니다.
