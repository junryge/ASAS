**피크 689 도달** (13:47). 이는 전체 데이터 최고값에 근접.

### 2단계 해석
- M14 에서 M16 으로 가는 물동량이 30분간 계속 쌓임

- 하지만 이 룰만으론 **16:00 가짜 경보 시점에도 발동** → 단독으론 확정 불가
- → "주의보" 수준. 관리자 알림 가능하나 조치까진 애매

**3조건 AND 모두 만족** → **3단계 확정 발동** ⭐

### 의미
- **14:00 데드락 정확히 10분 전**
- 이제 "예측"이 아니라 **"확정"** 수준의 경보
- 운영자 즉각 대응 시작할 수 있는 시점

### 왜 이 시점이 결정적인가
- 3 지표가 "우연의 일치" 로 동시 만족할 확률이 매우 낮음
- 특히 **R-C' (전체 감소 + 역증가)** 는 데드락 고유 패턴
- 16:00 가짜 경보 시점엔 리프터가 오히려 증가 중이라 발동 안 함

## 💡 시나리오에서 배운 것

### 1. 조기 신호는 시끄럽고, 확정 신호는 조용하다
- 1단계 (1MIN 9분+): 전 구간에서 36회 발동 — 참고용
- 2단계 (M14→M16 +100): 11회 — 주의
- 3단계 (AND): **단 3회만** — 모두 진짜 데드락

### 2. 일시 완화(13:15~30)에 속지 않아야
- 표면 수치는 정상화 보이지만
- 밑에서 M14→M16 누적 진행 중
- **룰은 13:13부터 계속 2단계 경고 중** 이었음

### 3. 리프터 역증가가 진짜 차별 지표
- 14:00 (진짜): 전체 감소 + 특정 리프터만 증가
- 16:00 (가짜): 전체 증가 + 여러 리프터 증가
- → **"추세와 반대 방향"** 이 핵심

### 4. 운영자 증언이 데이터 분석 방향 지어줌
- "MLUD 쏠림" → MLUD Q 추이 확인
- "리프터 영향" → 10개 리프터 개별 분석
- → 도메인 지식 + 데이터 분석 **시너지**
