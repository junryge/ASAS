## 3. 룰베이스 사건단위 스크립트 (`3단계_룰베이스_사건단위.py`)

### 사용법
```bash
python3 3단계_룰베이스_사건단위.py STAR.csv
python3 3단계_룰베이스_사건단위.py STAR.csv -o 출력.csv
```

### 출력 (2개 CSV)

#### A. 사건단위 CSV
```
사건단위_YYYYMMDD_HHMMSS.csv
```
컬럼 (15개):
```
file, date, predict_time, start_time, end_time,
lead_min, duration_min, refire_count,
max_1min, max_m14_diff, max_reverse_lifters,
primary_cause, contrib_breakdown, anomaly_explanation,
early_warning
```

`early_warning` 예시:
```
"13:30 1·2단계 발동 → 13:50 3단계 확정 (20분 먼저 인지)"
```

#### B. 발동이벤트 CSV (실시간 타임라인)
```
사건단위_YYYYMMDD_HHMMSS_발동이벤트.csv
```
컬럼 (9개):
```
file, datetime, date, time,
stage, stage_name, prev_stage, transition, reason
```

예시:
```
13:30  0→2  2단계 주의보   M14→M16 +34 (10분 fast)
13:31  2→1  1단계 조기경보  1MIN ≥6분 지속
13:33  1→0  정상화
...
13:43  1→2  2단계 주의보   M14→M16 +105 (30분간)
13:50  2→3  3단계 ⭐확정    AND 만족
```

### 작동 원리

```
입력 CSV → 한 줄씩 처리
  ↓
90분 슬라이딩 윈도우 (deque maxlen=90)
  ↓
매 분 룰 평가:
  · R-A' (1MIN ≥9분 1회+) OR ra_sustained (6분 5분창 3회+)
  · R-B  (M14→M16 +100/30분) OR rb_fast (+30/10분)
  · R-C' (리프터 합 감소 + 역증가 2개+)
  · S1 = R-A' 2회+ OR ra_sustained
  · S2 = R-B OR rb_fast
  · S3 = R-A' AND R-B AND R-C'
  ↓
사건 추적 (FSM):
  IDLE        + s3 신규     → IN_INCIDENT
  IN_INCIDENT + s3 (10분+)  → 같은 사건 재발동
  IN_INCIDENT + 10분 무 s3  → IDLE (사건 종료)
  ↓
predict_time = S3 발동 시점에서 60분 lookback,
               그 안의 최초 S1/S2 발동 시각
```

### 데이터 준비 가이드

| 시나리오 | 받아야 할 범위 | 결과 |
|---|---|---|
| 알려진 사건 분석 | 사건 시작 90분 전 ~ 사건 종료 후 | 사건 1건 + 발동이벤트 다수 |
| 미지의 사건 탐색 | 하루 전체 (0:00 ~ 23:59) | 그날 모든 S3 사건 |
| 실시간 운영 | 현재 기준 과거 90분 (지속 갱신) | 발동이벤트만 출력 |

## 4. 운영 코드 (`WORD_MODEL/WORLD_SIM`)

### 상태: **튜닝 통합 완료, 그대로 둬도 됨**

| 파일 | 역할 | 통합 상태 |
|---|---|---|
| data_loader.py | STAR CSV 로드 | ✅ 신규 키 5종 추가 (avgtotal1min, m14_to_m16, lft_list, mlud_q, fab_trans_job) |
| macro_predictor.py | 실시간 룰 평가 + 사건 추적 | ✅ R-A'/R-B/R-C' + 튜닝(ra_sustained, rb_fast) 모두 적용 |
| replay_engine.py | 데이터 재생 + precompute | ✅ precompute_timeline() 호출 추가 |
| dashboard.html | UI 표시 | ✅ 3단계 배지 + 클릭 모달 (타임라인 표시) |

### Production 코드 vs 분석 스크립트 룰 일치

```
production:  WORD_MODEL/WORLD_SIM/macro_predictor.py
분석:        WORD_MODEL/OHS_DATA_MD/3단계_경보_검증_스크립트.py
운영시뮬:    WORD_MODEL/OHS_DATA_MD/3단계_룰베이스_사건단위.py

→ 셋 다 동일한 R-A'/R-B/R-C' 룰 + 튜닝 적용
→ 결과 일치
```

### 운영 시 사용 흐름

```
실시간 STAR 데이터
  ↓
macro_predictor.update() 매 분 호출
  ↓
get_prediction() 결과를 API 로 노출
  ↓
dashboard.html 이 폴링하여 배지 + 모달 갱신
  ↓
사용자가 3단계 배지 클릭 → 타임라인 모달 (사건 진행 시각별)
```

## 5. 룰 정의 (3개 모두 동일)

| 룰 | 조건 | 의미 |
|---|---|---|
| R-A' | 1MIN ≥ 9분이 10분창 1회+ | 반송 시간 스파이크 |
| ra_sustained | 1MIN ≥ 6분이 5분창 3회+ | 반송 시간 지속 (튜닝) |
| R-B | M14→M16 +100/30분 | FAB 간 큐 누적 |
| rb_fast | M14→M16 +30/10분 | FAB 간 큐 빠른 누적 (튜닝) |
| R-C' | 리프터 합 감소 + 역증가 2개+ | 경로 병목 |

### 단계 판정
```
S1 = R-A' (count >= 2) OR ra_sustained
S2 = R-B OR rb_fast
S3 = R-A' AND R-B AND R-C'  (불변, 04-21 검증 보호)
```
