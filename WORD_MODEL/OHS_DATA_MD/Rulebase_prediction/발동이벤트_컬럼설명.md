## ⚡ 운영자 빠른 판단 흐름

```
1) stage 확인
   ├─ 0 → 통과
   ├─ 1 → 로그만
   ├─ 2 → 주시
   └─ 3 → ★ 즉시 대응
        ↓
2) hot_area 확인 → 어디서 시작?
        ↓
3) reason 확인 → 왜?
        ↓
4) propagation_chain → 어디로 번지나?
        ↓
5) {hot_area}_signals 확인 → 어떤 룰?
        ↓
6) 해당 영역 상세값 확인:
   - {area}_ra (시간)
   - {area}_rb_diff30 (양 증가)
   - M16HUB_rev_count / rev_lids (위치)
   - M16HUB_rd_fab / stb_util (공간)
   - sla_{area} (4분초과)
   - sorter_{area} (Sorter)
```

## 🎯 한 줄 요약

| 보는 순서 | 컬럼 |
|---|---|
| 1. **위험 여부** | `stage` (3=사건확정) |
| 2. **변화 인지** | `transition` (예: `→3` 시작, `3→1` 종료) |
| 3. **어디 위험?** | `hot_area` + `affected_areas` |
| 4. **왜?** | `reason` + 해당 영역 `signals` |
| 5. **얼마나 위험?** | `unified_risk_level` (점수 기반) |
| 6. **전파?** | `propagation_chain` |

**핵심: `stage=3` 이면 무조건 대응. 나머지는 참고.**
