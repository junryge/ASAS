## 1. 시스템 한눈에 보기

### 무엇을 하는가
**반도체 FAB 8개 영역에서 OHT 반송 중 발생하는 정체/데드락을 30~90분 전에 사전 감지**합니다.

- 매분 데이터 수집 → 매분 룰 평가 → 위험 등급/원인 영역/전파 경로 자동 출력

## 4. 5종 룰 — 무엇을 어떻게 잡는가

### ① 영역별 4축 룰 (R-A' / R-B / R-C' / R-D)

> 각 영역마다 4개 축으로 정체 감지

| 축 | 의미 | 운영자 관점 질문 |
|---|---|---|
| **R-A' (시간)** | 반송이 비정상적으로 느려짐 | "OHT 가 느려졌나?" |
| **R-B (양)** | 인플로 큐가 누적됨 | "큐가 쌓이나?" |
| **R-C' (위치)** | 특정 장비/방향에 쏠림 | "한쪽으로 몰리나?" |
| **R-D (공간)** | 저장공간 / 가동률 가득참 | "공간이 막혔나?" |

**잡는 정체 유형**:
- 일반 데드락: R-A' + R-B + R-C' 동시 발동
- 폭주형: R-A' + R-B(fast) + R-C'
- **공간 막힘형**: R-A' + R-D + R-C' (5/7 SFA 정체 같은 케이스)

### ② 흐름 룰 — 9개 핵심 노드 비율 감시

> 현재값 / 30분 평균 비율로 흐름 이상 감지

| 비율 | 등급 |
|---|---|
| ≥ 1.5x | 주의 |
| ≥ 2.0x | 위험 |
| ≥ 3.0x | 심각 (예: M14→M16HUB 2.9x 병목) |

### ③ SLA 룰 — 4분 초과 반송 비율

> 정체의 직접 결과 지표

| 영역 | 임계 |
|---|---|
| M16HUB | ≥ 5% |
| M14 | ≥ 25% |
| M16A | ≥ 13% |
| M16B | ≥ 18% |

### ④ Sorter 룰 — LOT 적체 감지

> 영역별 SORTERWAITCOUNTOVER 임계 초과 시 발동

| 영역 | 임계 |
|---|---|
| M14B | ≥ 75 |
| M16B | ≥ 90 |
| M14 | ≥ 100 |
| M16A | ≥ 180 |

### ⑤ MAXCAPA 룰 ★ (신규 — 운영자 변수 활용)

> **운영자가 메신저에서 변경하는 6개 값** = 운영자가 정체를 인지한 직접 신호

| 컬럼 | 정상값 | 감지 임계 |
|---|---|---|
| M16HUB.QUE.LFT.3F_LFT_MAXCAPA | 165 | ≤ 100 |
| M16HUB.QUE.LFT.3F_M14BLFT_MAXCAPA | 66 | ≤ 50 |
| M16HUB.QUE.CNV.3F_CNV_MAXCAPA | 129 | ≤ 80 |
| M14.QUE.CNV.3F_CNV_MAXCAPA | 244 | ≤ 150 |
| M16A.QUE.LFT.2F_LFT_MAXCAPA | 54 | ≤ 40 |
| M16A.QUE.LFT.6F_LFT_MAXCAPA | 149 | ≤ 100 |

→ MAXCAPA 가 정상값에서 임계 이하로 떨어지면 **운영자 인지 시점** → 사건 발생 가능성 매우 높음.
