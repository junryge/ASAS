## 3. hubroom 예측기 OHT 가감점 (오탐 줄이기)

입력 CSV(수집기 `M16A_HUBROOM_PR.csv`)의 `{FAB}_OHT_report · _missing · _JAM · _HT_STOP` 을 보고 점수를 올리고 내린다.
설정은 전부 `thresholds.json` (`OHT_ADJ_ENABLED` · `OHT_ADJ_FABS` · `OHT_ADJ_ALL` · `OHT_ADJ_FAB`), 고친 뒤 예측기 재시작.

| 조건 (적용 FAB = M16HUB) | ALL `unified_risk_score` | FAB `{FAB}_score_raw` |
|---|---|---|
| 미보고 ≥5 **그리고** JAM ≥10 | +15 | +15 |
| 위가 아니고 미보고 ≤5 **그리고** JAM ≤10 | **−10** | **−10** |
| HT_STOP ≥1 | +10 | +10 |
| HT_STOP 0 | 그대로 | 그대로 |

- 미보고 · JAM 규칙과 HT 규칙은 따로 계산해서 더한다 (예: 미보고3 · JAM4 · HT2 → −10 + 10 = 0)
- 경계값(미보고 5 · JAM 10 정확히)은 + 우선 · report 비었거나 0 이면 가감 안 함
- ALL 은 0~100 안에서 — 등급 · 사건도 가감된 점수로. FAB 은 score_raw 에만 (ALL 합산에는 안 들어감)
- 평소엔 거의 매분 −10 이 붙는다 (정상 동작)
- 기록 칸: `unified_risk_score_orig` · `oht_all_adj` · `{FAB}_oht_adj` · `{FAB}_score_raw_orig` · `oht_signals`
- 10/7: FAB 감점을 −15 · −13 으로 바꿔 보다가 **처음 규칙(−10)으로 되돌림** — 지금 값이 확정
