## 5. 장애 예방 시스템 관점 — 왜 추천 임계 폐기인가

```
Miss(놓침) ≫ FP(오탐)
  - 장애 놓치면 → 실제 사고 (치명적)
  - 오탐 1건 → 알람 한번 더 (경미)
```

→ 추천 임계(재현율 12% = 88% 놓침)는 **사고 위험**. v4.1(재현율 45%)이 차라리 안전.
→ 이전 `5월_30일_검증결과.md` 의 "추천 임계 좋다"는 **정상가동일 FP 관점**. 실제 장애 탐지 관점에선 정반대.
