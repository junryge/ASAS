하이브리드 정체 30분 사전예측 — 핵심기술

M16A Hubroom · 룰베이스 + 정상 TSPulse + 비정상 TSPulse → 하이브리드 판정

운영자가 정체를 보고하기 30분 전, 서로 다른 3개 탐지기가 합의하여 정체 전조를 미리 알린다.

1. 3층 아키텍처

룰베이스 도메인 임계 규칙 (경계50/위험71/초위험85)확실·설명가능 · 그러나 규칙 밖은 못 봄
＋

＋
비정상 TSPulse 정체만 학습 → "진짜 정체?" 확인관오탐 제거 · 그러나 정체 데이터 적음
▼
하이브리드 판정 3개 종합 → 최종 등급 + 신뢰도합의가 많을수록 신뢰 높음

2. 핵심기술 — 재구성 이상탐지 (TSPulse R1)

① 정상만 학습

라벨 불필요. 정상 패턴을 재구성하도록 학습 → 평소와 다른 급증(정체 전조)은 재구성 실패 → 오차 큼 = 이상.

② 대칭 확인관

비정상 모델은 정체를 재구성. 후보가 정체모델서 오차 낮으면 = 정체 패턴 → 확정. 둘 다 높으면 = 정체 아닌 이상(설비작업).

③ 초경량

1.08M 파라미터. CPU로도 동작, 폐쇄망 오프라인 반입 가능. 시계열 네이티브(롤링·델타 수작업 불필요).

④ 누수 차단

학습창은 시각 t까지 과거만. 작업일정·정체 구간을 데이터에서 제거한 순수 정상만 학습.
