① 최종 아키텍처

파랑=ML · 주황=룰 안전망 · 마젠타=정답(라벨) 파이프 · 아쿠아=판정/파생. ML과 룰이 병렬로 돌고 최종은 둘 중 높은 등급.

② 핵심 기술 3가지

1. CUSUM — 서서히 밀리는 조짐을 잡는 눈

C(t) = max(0, C(t-1) + [현재값 − 직전120분 중앙값 − 0.5×표준편차])

순간 스파이크는 누적이 안 돼 무시되고, 조금씩이라도 지속 상승하면 쌓여서 경보. 절대 임계로는 노이즈에 묻히던 국소 밀림(큐 66→108)이 CUSUM으론 뚜렷해진다(270→1007). 피처로도 들어가고(ML이 학습), 독립 룰로도 동작(안전망).

2. 정답 = 고객이 확인한 사건 (라벨 혁신)

룰엔진(hubroom) 점수만 정답으로 쓰면 국소 밀림을 "정상(12~47점)"으로 가르치게 된다 — 6월 4개 사건으로 증명. 운영 메신저에서 파서로 추출한 실제 사건(4~5월 261건)을 정답에 합치자 ML이 몰림 클래스를 배우기 시작 (6/29 몰림·6/19 몰림을 XGBoost가 직접 탐지, 30분 모델 신뢰도 77% 한계 → 99% 돌파).

3. 등급 = 정밀도 캘리브레이션

"위험"이라는 등급은 그 경보가 맞을 확률로 정의: 30분 모델 p≥0.5→신뢰 87%, p≥0.6→95%, p≥0.7→99% (학습기간 4~5월 내부검증 기준). 6월 실전 적중률은 ④의 운영자 채점(30분 54% · 10분 56%)이 기준.

③ 개발 여정 — 8단계 시행착오

  • 1. TSPulse R1 이상탐지과탐지 25%/일 — 자기참조 정규화가 원인
  • 2. TSPulse + 고정 기준선과탐지 6%로 개선, 6/5를 262분 전 탐지. 그러나 국소밀림 불가·512분 고정 → 제외
  • 3. XGBoost + hubroom 라벨큰 정체(6/2·6/5)는 정탐(정밀도 77%), 국소밀림 0/4
  • 4. 방향피처(DIR)·STK 추가여전히 0/4 — 피처가 아니라 정답이 문제라는 확신
  • 5. 원인 확정 (발동이벤트 원본 검증)4개 사건의 hubroom 점수 = 12~47(정상). hubroom 라벨로는 영원히 못 배움 — 증명 완료
  • 6. SOP 절대임계 시도Bridge Time 상승은 확인했으나 6월은 만성 과부하(중앙값 5.85분)라 절대값은 노이즈
  • 7. CUSUM 밀림룰누적상승 방식으로 4/4 탐지 (13~30분 전)
  • 8. 메신저 정답 + 전문가 피처 재학습ML 자체가 6/29·6/19·6/2·6/5 직접 탐지 — 정답을 바꾸니 모델이 배웠다

교훈: 실패의 원인은 모델이 아니라 정답지였다. 고정 임계가 못 보는 사건을 그 임계의 라벨로 가르칠 수는 없다.

⑤ 사용법

학습 (최초 1회 / 새 달 편입 시)

:: 0. 피처 + 발동이벤트
python features_31.py --raw .\RAW --start 2026-04-01 --end 2026-05-31 --out .\out_ml
for %f in (RAW\*.CSV) do python hubroom_predictor.py "%f" -o .\predict_tobe

:: 1. 메신저 → 사건 추출 (정답)
python 운영로그_파서_v2.py 4월_5월.TXT --out .\ep45

:: 2. 전문가 피처 병합 (43→73)
python 피처병합_발동이벤트.py --features .\out_ml\features.csv --events .\predict_tobe --out .\out_ml\features_확장.csv

:: 3. 통합 라벨 → 4. 학습
python xgb_라벨_통합.py --features .\out_ml\features_확장.csv --episodes .\ep45\{생성}_episode.csv --events .\predict_tobe --out .\out_ml\labels_통합.csv
python xgb_비정상_train.py --features .\out_ml\features_확장.csv --labels .\out_ml\labels_통합.csv

python features_31.py --raw .\OUT_7 --start 2026-07-01 --end 2026-07-31 --out .\out_ml\july
for %f in (OUT_7\*.CSV) do python hubroom_predictor.py "%f" -o .\predict_tobe_7
