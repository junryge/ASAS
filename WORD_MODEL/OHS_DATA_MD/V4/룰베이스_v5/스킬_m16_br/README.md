# m16_br LLM 스킬 4종

`한줄분석.py` / `발동이벤트_점수분석.py` / `reason_컬럼찾기.py` 를 **파이썬 없이 LLM 만으로** 재현하는 Claude 스킬 + 배경 설명 스킬.

## 스킬 목록

| 스킬 | 역할 | 대응 파이썬 |
|---|---|---|
| `m16_br_한줄분석` | 발동이벤트 데이터 한 줄 → 점수 분해 | 한줄분석.py |
| `m16_br_점수분석` | 여러 줄 → 최고점 분석 | 발동이벤트_점수분석.py |
| `m16_br_reason찾기` | reason 텍스트 → 원본 컬럼 | reason_컬럼찾기.py |
| `m16_br_카파시` | 점수·등급·룰 **왜/개념** 설명 (배경 지식) | — |

## 설치 (Claude Code)

각 스킬 폴더를 스킬 디렉터리로 복사:

```
~/.claude/skills/                      ← (전역, 모든 프로젝트)
  ├─ m16_br_한줄분석/SKILL.md
  ├─ m16_br_점수분석/SKILL.md
  ├─ m16_br_reason찾기/SKILL.md
  └─ m16_br_카파시/SKILL.md
```
또는 프로젝트 루트의 `.claude/skills/` 아래에 두면 그 프로젝트에서만.

## 사용

대화창에서:
- "발동이벤트 한 줄 분석해줘" + 데이터 붙여넣기 → `m16_br_한줄분석`
- "이 reason 무슨 컬럼이야" + reason 텍스트 → `m16_br_reason찾기`
- "점수 체계 설명해줘" → `m16_br_카파시`

또는 `/m16_br_한줄분석` 처럼 직접 호출.

## 파이썬 버전과 차이

| | 파이썬 도구 | LLM 스킬 |
|---|---|---|
| 실행 | python 필요 | **LLM 만 (설치 X)** |
| 출력 | 고정 텍스트 | 동일 형식 + 자연어 해석 추가 가능 |
| 환경 | cmd/터미널 | Claude 대화창 |

둘 다 같은 컬럼 매핑·임계·등급을 쓰므로 결과는 동일.
