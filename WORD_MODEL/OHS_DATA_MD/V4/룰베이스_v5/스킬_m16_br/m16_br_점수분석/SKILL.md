# m16_br 점수분석

⛔ **규칙**
1. 분석 블록은 `m16_br_한줄분석` SKILL 의 **출력 템플릿 그대로** (1개 행당 1블록, 코드블록 안 monospace).
2. 분석 블록 자체는 변형 금지.
3. 최종 결론/조치 권고는 분석 블록 **아래** 에 짧게 추가 (허용).

## 처리
1. 입력 받은 여러 행 각각 CSV 파싱.
2. `unified_risk_score`(신 13번째 / 구 9번째 컬럼) 추출.
3. 기본: **점수 최고 1개 행** 분석.
4. 사용자가 "상위 N개"/"top N" 요청 → 점수 내림차순 N개 분석.
5. 사용자가 시각(HH:MM) 지정 → 그 행만 분석.

## 추가 출력 (요약 한 줄, 분석 블록 앞)
```
>>> 입력 {N}행 중 최고점: {datetime} 점수 {max} [{등급}]
```

## 분석 블록
`m16_br_한줄분석` SKILL.md 의 "출력 템플릿" 과 "출력 예시" 를 **그대로 따른다**. 컬럼매핑·임계·등급·판정마크·룰 한글명 전부 동일. 분석 블록 끝나면 그 아래 최종 결론(한줄분석 SKILL 의 "📌 최종 결론" 형식)을 덧붙인다.
