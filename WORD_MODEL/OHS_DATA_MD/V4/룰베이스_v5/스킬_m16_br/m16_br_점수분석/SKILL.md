# m16_br 점수분석 (LLM 버전)

발동이벤트.csv 의 **여러 행**을 받아 `발동이벤트_점수분석.py` 와 동일하게 **점수 최고점**을 찾아 분석한다.

## 입력
사용자가 발동이벤트.csv 의 데이터 여러 줄(또는 시간 구간 전체)을 붙여넣음.

## 동작
1. 각 행을 CSV 파싱 → `unified_risk_score`(13번째 컬럼, 구버전이면 9번째) 추출.
2. 기본: **점수 최고 1개** 행 분석. 사용자가 "상위 N개" 요청 시 점수 내림차순 N개.
3. 사용자가 특정 시각(HH:MM) 지정 시 그 행 분석.
4. 각 분석은 `m16_br_한줄분석` 스킬과 동일 형식으로 출력.

## 컬럼 순서 / 점수산식 / 등급 / 룰매핑
→ `m16_br_한줄분석` 스킬의 정의를 그대로 따른다 (135컬럼/131컬럼, 점수 = layer1+flow+sla+sorter+mc, 등급 0~99 정상 / 100 관심 / 120 주의 / 130 경계 / 160 위험 / 220 발동).

## 추가 출력 (여러 행 비교 시)
최고점 분석 전에 요약 한 줄:
```
>>> 입력 {N}행 중 최고점: {datetime} 점수 {max} [{등급}]
```
그리고 상위 N개 모드면 각 행을 점수 높은 순으로 차례로 분석.

## 핵심
- 같은 사건이라도 분(分)마다 점수가 다름. 최고점 분이 그 사건의 max_risk_score 와 일치.
- 점수 최고점 행을 보면 "어느 영역/룰이 가장 셌을 때" 가 드러남.
