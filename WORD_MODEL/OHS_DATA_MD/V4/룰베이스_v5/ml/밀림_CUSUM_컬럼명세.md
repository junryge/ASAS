# 밀림 방향감지기 (CUSUM) — 입력 컬럼 상세 명세

> **역할:** 룰베이스가 못 보는 **국소 컨베이어 밀림**(남측 4AFC3201 / 북측 4AFC3301 / 허브)을
> 큐의 "지속 상승"으로 감지. 학습·라벨 불필요(무지도). 6월 4개 사건 4/4 포착 확인.

> **왜 방향당 1개면 되나:** 밀림은 "그 방향 큐가 평소보다 계속 높은 상태"로 나타남.
> CUSUM은 그 지속 상승만 누적하므로 큐 count 하나로 충분. (순간 튐은 무시됨)

## 2. 보조 입력 — 허브 저장 하드경보 (즉시 경보용)

CUSUM은 "서서히 쌓이는" 걸 잡음. 반면 **이미 꽉 찬 상태**는 즉시 경보해야 함 → 절대값 룰 3개:

| 피처명 | 원본 센서 | 조건 | 의미 |
|---|---|---|---|
| `RD_STK` | `M16HUB.STRATE.STK.STORAGERATIO` | **≥ 10%** | STK 스토커 저장률. 평소 0 → 10%만 넘어도 저장Full 직결(6/16형). **단독 하드경보** |
| `RD_STB` | `M16HUB.STRATE.STB.3F_STORAGE_UTIL` | ≥ 99% | STB 3F 이용률. 평소에도 높아 → SLA 같이 확인 |
| `SLA_M16HUB` | `M16HUB.QUE.ALL.TRANSPORT4MINOVERRATIO` | 4분초과율 | 반송 4분초과 비율. 저장경보 진위 확인용 |

**저장 하드경보 로직:**
```
경보 = STK ≥ 10%  (단독 확정)
      OR ( (FAB ≥ 25% 또는 STB ≥ 99%) AND 정체 동반 )
```

## 4. CUSUM 수식 (핵심 로직)

```
기준선(base)  = 직전 120분 큐의 중앙값 (과거만 → 누수 없음)
표준편차(sd)  = 직전 120분 큐의 표준편차
여유(slack)   = K × sd   (K = 0.5, 작을수록 민감)

C[i] = max( 0 ,  C[i-1] + ( 큐[i] − base − slack ) )
```

- **큐가 평소(base)+여유를 지속적으로 넘으면** C가 계속 누적 → 커짐
- **순간 튐**은 다음 분에 다시 내려가면 C가 0으로 리셋 → 무시
- **파라미터:** 기준창 120분 / K=0.5 (train·infer 동일해야 함)

## 5. 등급 → 예측/미예측

CUSUM이 임계의 몇 배인지로 내부 등급 매김:
| CUSUM / 임계 | 내부등급 |
|---|---|
| 1.0 ~ 1.5배 | 경계 |
| 1.5 ~ 2.5배 | 위험 |
| 2.5배 ↑ | 초위험 |

**게이트(오탐컷) 후 최종:**
- 초위험 → 밤낮 항상 `예측`
- 위험 → 주간(08~19시)만 `예측`
- 경계 → `미예측`(참고만)
