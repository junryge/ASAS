# 4~5월 학습 파이프라인 사용법 (최종판)

> **구조**: X = 원신호 43 + 발동이벤트 전문가 30 (→롤링/델타/CUSUM 자동파생 ~800)
> **y** = 메신저 episode(고객 확인 사건) ∪ hubroom≥50(큰 정체) ∪ 수동 사건
> **모델** = XGBoost 2개 (10분 / 30분 예측) · **검증** = 6월 홀드아웃

---

## 0. 준비물 체크 (ml 폴더 기준)

| 파일/폴더 | 내용 | 없으면 |
|---|---|---|
| `out_ml\features.csv` | 4~5월 43피처 (features_31.py 산출) | ①-0 실행 |
| `predict_tobe\` | 4~5월 발동이벤트 61일 | 이미 있음 |
| `20260612_065558_episode.csv` | 5월 메신저 사건 56건 | 있음 (없으면 요청) |
| `out_ml\june\features.csv` | 6월 43피처 | ①-0 june 버전 |
| `predict_tobe_6\` | 6월 발동이벤트 | 이미 있음 |

```cmd
:: ①-0 (features 없을 때만) 4~5월 / 6월 피처 생성
python features_31.py --raw .\RAW   --start 2026-04-01 --end 2026-05-31 --out .\out_ml
python features_31.py --raw .\OUT_6 --start 2026-06-01 --end 2026-06-30 --out .\out_ml\june
```

## 1. 학습 (4~5월) — 3줄

```cmd
:: ① 피처 확장: 발동이벤트 전문가 30컬럼 병합 (43→73)
python 피처병합_발동이벤트.py --features .\out_ml\features.csv --events .\predict_tobe --out .\out_ml\features_확장.csv

:: ② 통합 라벨: 메신저(밀림) + hubroom≥50(큰정체)
python xgb_라벨_통합.py --features .\out_ml\features_확장.csv --episodes .\20260612_065558_episode.csv --events .\predict_tobe --out .\out_ml\labels_통합.csv

:: ③ 학습 (10분/30분 2모델)
python xgb_비정상_train.py --features .\out_ml\features_확장.csv --labels .\out_ml\labels_통합.csv
```

**각 단계 확인 포인트:**
- ①: `발동이벤트 매칭 XX%` — **90% 이상**이어야 정상 (낮으면 predict_tobe 기간 확인)
- ②: `[메신저] episode 56건` — **0건이면 중단**하고 episode.csv 형식 공유
- ③: `PR-AUC` + `top5` 에 전문가 컬럼(`M16HUB_score__…`, `rb_diff…`)이나 `__cusum` 등장하는지

## 2. 검증 (6월 홀드아웃) — 3줄

```cmd
:: ④ 6월도 같은 방식으로 피처 확장 (스키마 일치 필수!)
python 피처병합_발동이벤트.py --features .\out_ml\june\features.csv --events .\predict_tobe_6 --out .\out_ml\june\features_확장.csv

:: ⑤ 추론 (XGBoost + 저장룰 + CUSUM밀림룰 통합 판정)
python xgb_비정상_infer.py --features .\out_ml\june\features_확장.csv --model .\out_ml\xgb --out .\out_ml\june_final.csv

:: ⑥ 사람이 볼 요약 (경보 구간만, 10분/30분 2파일)
python 경보요약.py --infile .\out_ml\june_final.csv
```

**성공 판정 (경보요약_30분.csv 에서):**
- ✅ 6/11 10:18 · 6/22 11:11 · 6/24 11:58 · 6/29 18:07 **전에** 경보 행 존재
- ✅ 6/2 · 6/5 유지 (기존 성능 안 깨짐)
- ✅ 6/4 조용

## 3. 자주 나는 오류

| 증상 | 원인/해결 |
|---|---|
| `피처 불일치 N개` (추론) | ④를 안 돌리고 원본 june features 로 추론함 → **학습·추론 둘 다 확장본** 사용 |
| `[메신저] episode 0건` | episode.csv 에 `t0`/`start_time` 컬럼 없음 → 파일 공유 |
| ③에서 `양성 0` | ② 라벨 통계 확인, features 와 labels 기간 불일치 |
| 매칭률 낮음 (①) | predict_tobe 에 4~5월 발동이벤트가 다 있는지 `dir` 확인 |

## 4. 파일 역할 한눈에

```
features_31.py            원본 RAW → 43피처 (DIR방향큐·저장·SOP파생 포함)
피처병합_발동이벤트.py     +발동이벤트 전문가 30컬럼 = 73피처   ★신규
xgb_라벨_통합.py          메신저∪hubroom∪수동 → y_pre10/30    ★신규
xgb_비정상_train.py       XGBoost 학습 (롤링/델타/CUSUM 파생 + 등급 캘리브레이션)
xgb_비정상_infer.py       추론 + 저장룰 + CUSUM밀림룰 → 최종등급/사유 (%표기)
경보요약.py               매분 상세 → 경보구간만 압축 (10분/30분 2파일)
```

수동 사건 추가하고 싶으면 (예: 새로 확인된 정체):
```
manual.csv:  2026-05-11 10:18,밀림   ← 한 줄에 하나
② 명령에 --manual .\manual.csv 추가
```
