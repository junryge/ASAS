# 03. 일반 스킬 — 응답 가이드

> LLM 응답 시 형식과 정확성 원칙. 임계 수치는 `04_임계값.md` 만 인용.

---

## 응답 흐름

```
1. 입력 데이터 종류 식별
   - raw IDC CSV (M16A_HUBROOM_PR.CSV) → 01_기준스크립트.md 알고리즘 적용
   - 발동이벤트 CSV (YYYYMMDD_발동이벤트.CSV) → 결과 해석만
   - 사건단위 CSV (YYYYMMDD_사건단위.csv) → S3 사건 상세

2. 평가 (또는 결과 읽기)

3. 결과 표 출력 (아래 템플릿)

4. 결론 + 권장 조치
```

## 정확성 원칙 (강제)

1. **임계 인용**: `04_임계값.md` 의 표 그대로. 자체 숫자 만들지 말 것.
2. **영역명**: M16HUB / M14 / M14B / M16A / M16B / M16 / M16_PKT / M16_WT 만.
3. **룰명**: R-A / R-A_sus / R-B / R-B_fast / R-C / R-D / SLA / SORT / MAXCAPA.
4. **단계명**: S1 조기경보 / S2 주의보 / S3 ⭐확정.
5. **등급**: 정상 / 관심 / 경계 / 주의 / 위험 / 매우위험 (6단계).
6. **추천 / v4.1 둘 다 비교** — 한쪽만 답하지 말 것.
7. **사례 인용** (5/8 등) 은 `02_카파시톤.md` 의 사건 사례 섹션에서만.

## 응답 길이 가이드

| 질문 유형 | 응답 길이 |
|---|---|
| "한 줄로 요약" | 1~2 문장 |
| "현재 상태" | 표 1개 + 결론 1줄 |
| "분석해줘" | 표 2~3개 + 결론 + 카파시 해설 1문단 |
| "보고서 만들어줘" | 위 템플릿 전체 |

소형 모델 (3~14B) 은 짧을수록 정확. 사용자가 "상세" 요청 시만 길게.

## 자주 묻는 질문 — 답변 예시

**Q: "M16HUB R-A 임계값?"**
A: 추천 12.0 분 / v4.1 원본 9.0 분 (`04_임계값.md` 참조).

**Q: "STB 99% 위험한가?"**
A: 정상 가동의 정점 (98~100%) 패턴. 추천 임계 101% 미만 → 안전. v4.1 99% → 매분 false positive.

**Q: "Sorter M14 246 LOT?"**
A: 정상 p50 = 243 LOT. 추천 임계 420 미만 → 정상. v4.1 100 → 항상 위반 (false positive).

**Q: "현재 데이터 어때?"**
A: [발동이벤트.csv 보고] [S3 분당 비율 / hot area / 결론] 형식으로.
