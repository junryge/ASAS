# 룰베이스_스킬 — LLM 챗봇용 자산 셋트

> 데모스 플랫폼 (Qwen3 35B 또는 소형 모델) 에 RAG/지식베이스로 등록 후
> 사용자가 raw CSV 또는 결과 CSV 를 첨부하면 LLM 이 본 문서들로 응답.

---

## 권장 흐름 — 정확성 우선

```
[운영자]  raw CSV 첨부
   ↓
[스크립트]  hubroom_predictor.py 실행 (자동 또는 사용자)
   ↓
   발동이벤트.csv (분당 평가 — 결정적, 정확)
   사건단위.csv (S3 사건 상세)
   ↓
[사용자]  결과 CSV 챗봇에 첨부 + 질문
   ↓
[LLM]  본 폴더 4 스킬 참조해서 해석
   ↓
[응답]  정확한 평가
```

**핵심**: LLM 한테 raw CSV 직접 평가시키지 말 것. 스크립트 결과를 해석하게 할 것.

## 데모스 환경별 흐름

### 케이스 A — Python 실행 가능
```
운영자: raw CSV 첨부 + "분석해줘"
LLM (자동): hubroom_predictor.py 실행 → 발동이벤트.csv 생성 → 해석 → 응답
```

### 케이스 B — Python 안 됨, 파일 첨부만
```
운영자 PC: python hubroom_predictor.py raw.csv -o predict_tobe
운영자: 발동이벤트.csv 챗봇에 첨부 + "분석해줘"
LLM: 결과 CSV 보고 해석 → 응답
```

### 케이스 C — raw 만 던지고 싶다 (소형 모델 한계 인지)
```
운영자: raw CSV 첨부 (M16A_HUBROOM_PR.CSV)
LLM: 01_기준스크립트.md 알고리즘 따라 추론 (정확도 70~85%, 환각 위험)
```

## 폴더 구조

```
룰베이스_스킬/
 ├─ 00_README.md            ← 본 파일 (LLM 행동 지침)
 ├─ 01_기준스크립트.md      ← 룰 평가 알고리즘 (raw 분석 시)
 ├─ 02_카파시톤.md           ← 1차 원리 (왜 이 룰?)
 ├─ 03_일반스킬.md           ← 응답 형식 + 정확성 원칙
 ├─ 04_임계값.md            ← ★ 정확 수치 (환각 방지 핵심)
 ├─ hubroom_predictor.py    ← 룰엔진 코드 (스크립트, Python 실행 가능 환경용)
 ├─ thresholds.json         ← 현재 운영 임계 (수정 가능)
 ├─ thresholds.recommended.json  ← 추천값 (2026-06)
 └─ 샘플데이터/
      ├─ M16A_HUBROOM_PR.CSV          (raw 90분, 265컬럼)
      ├─ 20260609발동이벤트.CSV       (분당 평가, 131컬럼, 861행)
      └─ 20260609사건단위.csv         (S3 사건 단위, 169컬럼)
```

## LLM 응답 원칙 (강제)

1. **임계값**: `04_임계값.md` 표만 인용. 자체 숫자 생성 금지.
2. **영역명**: M16HUB/M14/M14B/M16A/M16B/M16/M16_PKT/M16_WT 만.
3. **룰명**: R-A/R-A_sus/R-B/R-B_fast/R-C/R-D/SLA/SORT/MAXCAPA.
4. **단계**: S1 조기경보 / S2 주의보 / S3 ⭐확정.
5. **추천값 / v4.1 둘 다 비교** — 한쪽만 답하지 말 것.
6. **응답 형식**: `03_일반스킬.md` 의 템플릿 사용.
7. **사례** (5/8 사건 등): `02_카파시톤.md` 의 사례 섹션에서만 인용.

## 입력 데이터 유형별 LLM 동작

| 입력 | 우선 참조 스킬 | 응답 |
|---|---|---|
| `M16A_HUBROOM_PR.CSV` (raw 265컬럼) | 01_기준스크립트 + 04_임계값 | 분당 평가 (정확도 한계 있음) |
| `YYYYMMDD_발동이벤트.CSV` (131컬럼) | 03_일반스킬 + 04_임계값 | 결과 해석 (★ 권장) |
| `YYYYMMDD_사건단위.csv` (169컬럼) | 03_일반스킬 케이스 C + 02_카파시톤 | S3 사건 분석 |
| 질문만 ("R-A 임계가 뭐야?") | 04_임계값 | 표 인용 답 |

## 검증 5문제 (LLM 능력 테스트)

스킬 RAG 적재 후 다음 5문 정답률 측정:

1. **"M16HUB R-A 추천 임계값은?"** → 12.0분 (04_임계값.md)
2. **"STB 99% 는 정상인가?"** → 정상 분포 정점 (추천 101 미만 안전)
3. **"Sorter M14 246 LOT 어떤 상태?"** → 추천 420 미만 정상 / v4.1 100 위반
4. **"S3 확정 조건은?"** → any_RA AND (any_RD/SLA OR any_RC) AND (any_RB OR flow_severe)
5. **"5/8 사건 결과?"** → 113분 사전 감지 (운영자 인지 16:16 → 시스템 12:41)

**3개 이상 정확** → 운영 OK.
**2개 이하** → 컨텍스트/RAG 청크 보강 필요.

## 사용 시작

1. 본 폴더 7개 파일 (.md / .json / .py) 을 데모스 RAG 에 적재
2. 샘플데이터/ 의 CSV 로 테스트 질문 던지기
3. 검증 5문제 통과하면 → 실 데이터 사용 시작
