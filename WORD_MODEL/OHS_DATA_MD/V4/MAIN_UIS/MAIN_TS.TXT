<도메인 지식기반 내용>
0. M16 HUBROOM을 기준으로 연관된 반도체 FAB만을 기술한 정보이다.
1. 반도체FAB M16 HUBROOM(M16 Bridge)은  M14와 M16간 물류 이동을 가능하게 하는 공간이다.   
2. M16 HUBROOM 관련 반도체 FAB 건물 현황은 다음과 같다 
M14건물 : M14A(3F), M14B(7F), M14분석실(B1F) 
M16건물 : M16A(6F), M16B(10F), M16EUV(2F), M16WT(2F), R4(6F) 
M16 HUBROOM(3F) 
3. 다음은 FOUP이 이동하면서 경유하는 반송 장치에 대한 설명이다. 
VHL: foup을 레일을 통해 이동하는 장치. 각 장치 Port에서 Foup을 load하거나, 각 장치 port로 foup을 unload함. 
OHT : VHL를 제어하는 주체/시스템
LFT : 리프터. ZT라고도 불림. foup의 층간 반송을 담당. foup이 input port에 위치하면 rack master를 활용해 목적지 output port로 이동 
CNV : 컨베이어. foup이 input port에 위치하면 목적지 output port로 이동.
STK : 스토커. foup 임시 저장
STB : foup 임시저장. ZFS라고도 불림. 
Sorter : FOSB <-> Foup 변환 장치. Wafer가 입고되면 foup의 형태로 dumping되어 반송을 거치며 각 장비에서 공정시작. 대기Q가 많으면 그만큼 반송해야할 양이 많다는 방증
MLUD : FIO라고도 불림. 사람이 Manual Input에 foup을 위치시키면 Auto Output으로 이동해 OHT가 load하거나, OHT가 Auto Input에 위치시키면 Manual Output으로 이동해 사람이 get할수 있도록 하는 장치 
LFT/CNV/Sorter/MLUD : Foup기준으로 input port로 들어가서 output port로 나옴 port는 Manual/Auto Input/Output로 나뉜다. 따라서 4가지 종류가 가능 MI MO AI AO
STK/STB: Foup이 input port에 위치하면 rack master에 의해 shelf에 저장되고 호출시에 다시 output port에 위치함. 
port는 사람/시스템에 의해 활성화/비활성화 될수 있음 
4. 각 FAB의 연결정보  
4-1. M14A(3F)와 M16 HUBROOM(3F) 운 CONVEYOR(CNV)로 연결되어 있다. 
남측 CNV : 4AFC3201 / 북측 CNV : 4AFC3301
ex) M14A(3F)에서 M16으로 이동하고자 할때 M14A의 Foup은 cnv를 타고 M16HUBROOM(3F) 으로 이동하게됨. 이후 M16으로 이동 
4-2. M14A(3F)는 M10A(2F)과 LFT로 연결되어 있다. 
ex)M10A에서 M16으로 가고자 하면 LFT를 타고 M14A로 와서 M16HUBROOM(3F) 으로 이동. 이후 M16으로 이동    
4-3. M14B(7F)와 M14A는 LFT로 연결되어 있다. 리프터명 4ALF로 시작.  
4-4. M14B(7F)와 M16HUBROOM(3F) 은 LFT로 연결되어 있다. 리프터명 4ABLD로 시작. 
4-5. M14분석실(B1F)과 M16HUBROOM(3F)은 LFT로 연결되어 있다.
4-6. M16A(6F)와 M16HUBROOM(3F)은 LFT로 연결되어 있다. 리프터명 6ABL60~로 시작
4-7. M16A(6F)와 M16B(10F)은 LFT로 연결되어 있다. 리프터명 6ALF로 시작
4-8. M16A(6F)와 M16EUV(2F)은 LFT로 연결되어 있다. 리프터명 6ABL01~로 시작
4-9. M16A(6F)와 R4(6F)는 같은 층에 있지만 이동시 FAB간 반송으로 간주한다 (중간에 OHT명 변경)
4-10. M16EUV(2F)와 M16WT(2F)은 WIS STK로 연결되어 있다. (FAB간반송가상장비STK WIS_M16WT) 
  4-10-1. ex) M14A에서 M16WT로 이동하는경우 M14A->CNV->M16HUBROOM -> LFT -> M16EUV -> WIS STK -> M16WT 
5. 기타 
5-1. Sorter는 Wafer를 공정을 진행할수 있게끔 변환하는 장치로, SORTERWAITCOUNTOVER와 같은 지표가 급격히 증가하면 반송이 정체됐음을 유추할수 있어 엔지니어들이 유의깊게 관찰하는 지표
5-2. M16 HUBROOM에는 다수의 MLUD가 있으며 6FIOB로 시작함. 상황에 따라 M14A의 FOUP을 사람이 M16 HUBROOM MLUD에 투입하거나, VHL이 운송하여 M16 HUBROOM MLUD에서 나온 FOUP을 M14A로 직접 운반함 
     따라서 MLUD 관련 지표들도 유의해야할 지표
